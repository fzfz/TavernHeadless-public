# 角色显示领域

本领域描述角色状态在管理端和用户端之间共享的产品概念。

## 术语

**显示模板**：角色配置中定义消息内布局或整屏演绎布局、字段展示和可用操作的版本化资源。

**显示快照**：会话初始状态或某次变量提交形成的显示数据记录，包含当时的状态值和所使用的显示模板版本。

**对话记录**：一轮演绎中已经保存的用户输入、角色回复及补充消息。正文保存后，即使变量更新失败，该轮仍有对话记录。

**状态回看列表**：供用户选择会话初始显示快照和后续已提交显示快照的列表。变量更新成功提交后，列表增加对应的状态记录。

**剧情选项**：与会话初始画面或一条回复关联、供使用者选择的演绎指令。选项可以填写到输入框，也可以按角色配置作为用户消息发送。

**系统界面**：用户 Web 中承载账号、会话导航和聊天操作的应用界面。

**角色演绎内容区**：系统为角色显示模板提供的页面区域，容纳角色展示和系统聊天控件。

**角色交付包**：包含角色资料、世界书、开场、变量规则、前后端模块及所需资源的自包含交付集合。

**角色草稿**：作者正在编辑和预览的一套角色配置及资源，发布后形成可供会话固定使用的角色版本。

**角色附加模板包**：角色版本附带的布局、变量声明、显示资源与交互声明的集合，供系统解释执行。

**变量更新配置**：角色版本附带的变量结构、更新规则与计算规则，规定演绎内容如何产生下一份状态。

**变量更新提案**：针对固定前值与来源正文计算的候选变更，成功校验和提交后形成新的显示快照。
