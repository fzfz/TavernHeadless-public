# 生成执行领域

本领域描述角色演绎的执行身份及模型调用证据。

## 术语

**轮次**：一个会话分支中的逻辑演绎轮次，由楼层承载，包含用户输入与对应生成结果。

**运行**：系统为轮次启动的一次执行过程。运行具有独立身份，同一轮次可以先后经历多次运行。

**生成尝试**：一次运行内的一次候选结果生成过程。校验后重新生成属于新的生成尝试，同一尝试可以包含多个模型调用。

**模型调用**：向模型供应商发出的一次业务请求及其响应过程。供应商请求重试属于新的模型调用，数据库写入重试属于原调用记录的保存过程。

**调用记录**：一个模型调用的历史证据，包含当时的请求、响应或错误、时间及所属执行身份。

**角色应用**：供使用者开始演绎的角色入口，以及管理员为该入口绑定的角色卡、预设、世界书、正则、模型和启用能力的组合。

**发布配置**：角色应用发布时固定的资源版本和运行设置，供正式会话选择并固定使用。

**草稿修订**：管理员一次保存后确定的角色应用配置及其修订编号。试聊固定使用创建时的草稿修订。

**草稿试聊**：使用者基于草稿修订创建的演绎会话，用于检查发布前的角色行为。
