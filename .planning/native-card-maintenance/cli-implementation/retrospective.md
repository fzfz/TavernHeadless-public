# CLI实施复盘

## 1. 正确性

1. `begin`实际写入确定性人物字段、世界书条目及正则；待判断事项提供正文和关联原文文件，长内容提供分片。返回值仅含任务、包、待判断索引路径及事项数量。
2. JSON和PNG输入的逐项结构结果保存在[117项结果](corpus/results.json)。该检查核对输入读取及人物直接映射值；直接映射的1,236个人物字段值与原值一致，未验收角色卡的完整语义转换。
3. `copy`和`parse`将同一JSON的修改合并为一次写入；任一成员失败时保留原文件。不同目标文件的跨进程测试通过。世界书的共享索引通过批量或顺序调用更新。
4. A包生成后，测试修改包内容并生成B包，再显式导入及预览A包。正式接口导入、29文件回读、dry-run及页面均读取A包。请求、回读与截图保存在[联调目录](acceptance/)。
5. 同ID重试复用创建结果或正在运行的服务；已关闭、失败、输入冲突及未完成创建返回具体诊断。CLI收到SIGTERM信号后关闭预览服务并保存关闭结果，退出码为0。

## 2. 耗时与输出大小

1. 独立执行117项begin合计3.76秒，中位数23.77毫秒。
2. 使用[CLI大输入样本](../cli-audit/source.json)执行begin，耗时1.91秒。完整离线联调耗时25.25秒，其中预览启动3.65秒、浏览器命令15.01秒、关闭74.82毫秒。逐命令数据见[耗时记录](metrics.json)。
3. 最后一次全量测试耗时207.94秒，5,903项通过、4项跳过。

4. 上述CLI大输入样本的旧stdout为501,402字节，当前为167字节。
