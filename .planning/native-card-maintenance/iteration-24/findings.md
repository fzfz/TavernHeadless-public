# 实现与验收发现

## 1. 初始事实

1. 旧测试包 `.tmp/native-card-conversion/run-pdG3cp/role.zip` 包含155个文件；旧加载器选取其中145个JSON和3个后端JS。这145个JSON中，133个是 `worldbooks/linxi/entries/` 下同一本世界书的条目文件。
2. 当前 `codex/native-card-converter-design` 分支通过 `595bf26` 合并提交接入 `main` 的状态 Agent 实现；`ddbfbea` 提交为本分支的正式预览工具增加了独立状态预设绑定。

## 2. 规则条件及示例核对

1. 正式状态组装调用共享 `assemblePrompt`，传入当前更新前值作为 `stat_data`；原生世界书控制器在世界书扫描前生成对应条目正文。
2. 状态提示组装器按 `ruleFiles` 的配置顺序无条件连接各文件正文；条件规则应由世界书控制器返回原文或空文本，再由状态预设世界书节点读取。
