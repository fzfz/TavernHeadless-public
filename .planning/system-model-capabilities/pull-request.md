正式角色正文模型现在可以调用系统提供的 `random` 与 `calculate`，并在原生函数调用或文本工具协议中读取结果后继续同轮生成。发布、草稿试聊与原生卡试聊共享授权契约，系统按会话快照构建隔离目录，并在每次执行时核验当前授权和额度。

工具记录保留调用、生成尝试和步骤身份。正文提交事务只关联最终采用的执行记录；状态更新、派生和校验读取这些记录作为工具证据，并在重算时沿用原结果。角色作者文档、API schema、SDK、数据库迁移和测试随实现一起更新。

验证：`pnpm lint`、`pnpm typecheck`、`pnpm test:ci`、`pnpm sdk:generate && pnpm sdk:check`、`pnpm docs:build`。两种协议的正式 HTTP 测试采用固定供应商响应，保存了 dry-run、依赖调用、错误回传、正文归属和状态证据。真实模型采样及来源角色卡转换由原转换会话继续验收。
