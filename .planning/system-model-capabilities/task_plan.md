## 阶段
1. 主 Agent 核对基线与批准契约，产出 findings.md；入口与模块边界明确后完成该阶段。
2. 主 Agent 与执行代理实现执行器、授权配置、续步和证据，产出代码、schema、迁移与测试；定向测试通过后完成该阶段。
3. 主 Agent 保存验收证据并完成独立审阅与项目检查，产出 acceptance.md 和检查记录；全部验收条件通过后完成该阶段。
4. 主 Agent 提交并推送功能分支，按 docs/contributing.md 创建功能分支到 dev、dev 到 main 的 PR；两次 PR 的必需检查通过且最终合入 main 后完成该阶段。
