# 源内容的语义判断与转换归属

1. 表中路径相对于原生包；命名、格式和组件绑定见[目标文件与格式](conversion-map.md)。

2. “初始状态”指 `state/initial/<opening-id>.json`；“世界书条目”指 `worldbooks/<book>/entries/<name>.json`；“正文资料”指 `character.json` 或世界书条目，由正文模型读取。

## 2. 正则、页面与显示

1. | 看到的内容或规则                     | 属于什么内容       | 目标文件与执行者                                                      | 转换决定                                                                            |

   | 正则替换内容含 HTML、样式、事件函数  | 页面与交互         | `frontend/index.html`、`frontend/style.css`、`frontend/main.js`；前端 | 按钮中的剧情状态操作交给状态规则，确定性计算交给后端模块。旧匹配式按第6章判断删除。 |
   | 正则实际改变用户输入、提示或正文文本 | 文本变换           | `regex/<name>.json`；正式文本处理                                     | 保留仍需要的变换条件、作用范围和顺序；同一正则中的页面部分按上一行拆分。            |
   | 源界面依赖酒馆显示正文、接收输入和恢复失败楼层 | 宿主聊天功能 | `frontend/index.html`、`frontend/main.js`；前端 | 使用[系统聊天组件](api/script-api.md#111-apiwidgetsmountchat--挂载系统聊天组件)保留这些功能。 |
   | 页面发送前检查选项文本格式 | 发送条件 | `frontend/main.js`；前端 | 在人物宏展开后检查待发送文本。 |

2. 转换 Agent 默认忽略 `display` 通道的正则执行要求，禁止因该通道缺少执行入口停止转换或判定验收失败。同一规则在输入、提示或保存阶段的处理仍按对应通道转换；正则承载的页面、交互和人物剧情内容仍按本章及第6章判断。

### 2.1. 显示标签适配

1. 源卡要求模型输出显示标签时，转换 Agent 按[资料来源第2章](sources.md#2-只读实现依据)核对正文提取、正则处理与页面显示的执行顺序，并阅读标签内容及其使用位置，判断该标签承担显示标题、内容分区还是剧情摘要职责。禁止仅凭标签名称判断用途。
2. 显示标签与宿主提取标签冲突时，转换 Agent 必须选择不会触发宿主提取的新标签名，同步改写开闭标签、输出格式要求、示例、开场、仍需执行的匹配正则及程序中的关联引用，保留标签内原文、作用范围和处理顺序。禁止将这类冲突作为无法转换的理由，也禁止改写实际用于剧情摘要的标签。
3. 仅存在于静态页面、不会经过正文提取的HTML标签保持原样。

### 2.2. 页面配置与交互生命周期

1. 转换 Agent 读取页面配置的创建、修改和消费位置，确定条目在挂载前固定还是在运行中增删，并核对影响页面的字段、状态订阅、用户操作和卸载时的释放对象。
2. 固定条目采用预声明节点时，静态文案与资源只保存在 HTML 中，配置只保存节点 ID 和变化条件。转换 Agent 禁止在 HTML 和配置中重复维护同一文案或资源。
3. 转换 Agent 根据[布局注册与更新](api/script-api.md#101-apiuiregister--注册角色布局)、[元素事件](api/script-api.md#104-layouton--绑定元素事件)和[状态订阅](api/script-api.md#52-apivariableswatch--订阅快照变化)核对现有接口的组合实现，分别保持页面结构、变化状态和用户操作的职责。
4. 转换 Agent 核对源按钮的可读名称、锁定含义、资源失败反馈、滚动边界、弹窗焦点和关闭操作，保留相应行为。转换 Agent 分别核对资源加载中、成功和失败时的可读名称及反馈。资源可能在事件绑定前完成加载时，转换 Agent 同时处理已有加载结果和后续事件。
5. 转换 Agent 将事件回调中的 DOM 访问限定在当前实例，并按[运行时生命周期](api/script-api.md#1-入口与基本约定)核对事件监听、状态订阅和计时器的释放。全局事件的登记方式见[浏览器事件](api/script-api.md#134-apieventson--监听全局事件)。

   | --------------------------------------------------------- | ---------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
   | `[mvu_update]` 条目包含变量变化条件、建档、计数或重置要求 | 状态变化规则     | 状态规则；状态 Agent                                                               | 类型约束按第1章处理，计算按第4章处理，正文附带变量更新块的格式要求按第6章处理。 |
   | `[mvu_plot]` 条目包含人物、世界设定、事件流程或叙事要求   | 正文资料         | 世界书条目；正文模型                                                               | 保留有效内容及激活条件；其中的状态保存要求按第1章拆出，动态模板按本表末行处理。                                              |
   | 无路由标记或同时含两种标记的条目                          | 按内容确定的职责 | 正文资料、状态规则或对应模块                                                       | 按各部分的实际消费者拆分；标签的源路由含义见[MVU 架构](architecture.md#13-mvu-框架是什么)。                                  |
   | 禁用条目仍被脚本或规则按名称、ID 引用                     | 调用方使用的资料 | 剧情进入世界书条目；状态变化条件进入状态规则；模块数据进入 `data/<name>.json`      | 按[显式引用条目的处理](worldbook-fields.md#1-书级设置与内容职责)第4项保存内容并绑定读取者。                                                                                       |
   | 状态条件或模板决定本轮提示内容                            | 动态剧情规则选择 | `backend/controllers/<name>.js`、`backend/controllers/config.json`；后端提示控制器 | 读取调用方的条件、变量比较和辅助函数，按源顺序转写分支，返回选中条目的原文。                                                 |

2. 源脚本仅在条件成立时读取的状态规则保存在世界书条目中。转换 Agent 将完整条件和辅助函数转写到提示控制器，依据更新前的状态返回规则原文或空文本；状态预设通过世界书节点读取该条目。配置和节点用法见[状态提示词组装第4、6章](api/state-prompt-assembly.md#4-六个状态数据源)。

   | 后一步采样的参数或执行条件依赖前一步结果         | 顺序依赖           | 规则写入实际执行的前端、后端模块或正文资料                                                        | 使用前一步实际结果确定后续边界与分支；参数、候选、区间和权重从源卡取得。                                                            |

## 5. 冲突内容的处理

1. 转换 Agent 先核对冲突规则的对象、条件和时点；不同对象或事件各自保留，同一对象按源执行顺序及明示优先关系处理。源卡未说明优先关系、精度、舍入或重叠区间端点时，转换 Agent 保留原文并报告具体缺失。

## 6. 删除与改写的判断

1. 转换 Agent 删除一部分内容前，核对它的生成者、读取者及实际作用。转换 Agent 删除只服务于已退出的旧机制且不承载有效事实或业务规则的内容，并按对应职责处理兼有有效内容的部分。

2. | 看到的内容                                                                                                       | 处理决定                                                     | 有效内容的归属                                                                                                                                                                                                          |
   | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | 条目混合变量更新块格式和变量处理规则 | 逐条判断规则列表和格式正文 | 转换 Agent 仅删除旧更新块的生成要求、标签和示例；将当前值来源、合法路径及类型来源、变量缺失时的处理，以及例外条件下仍须执行的操作原文写入状态规则。条目标题、路由标签和格式字段不决定其他规则的去留。源操作格式按当前状态输出契约转写；类型写入 `state/schema.json`，可写路径写入 `agents/state-update/profile.json`。 |
   | 正则只隐藏、裁剪旧变量更新块，或限制历史中发送这些块的数量                                                       | 删除此正则                                                   | 业务变化规则按第1章承接；仍有作用的剧情历史筛选独立判断。                                                                                                                                                               |
   | 正则只清除旧变量分析文本或旧更新块的格式错误                                                                     | 删除变量更新块的格式清理规则                                 | 分别检查其他分析文本是否仍生成、是否仍需要变换；有效变换进入 `regex/<name>.json`。                                                                                                                                      |
   | 正则只挂载状态栏、页面或按钮；另一条正则只从提示中隐藏该挂载标记或 HTML                                          | 前端功能按第2章转换后，删除旧挂载与隐藏规则                  | 标记或 HTML 中的剧情事实、判定标签保留给实际消费者。                                                                                                                                                                    |
   | 提示要求正文输出状态栏占位符、变量快照或页面代码                                                                 | 删除正文输出状态栏标记、变量快照或页面代码的要求             | 原生前端读取正式状态；正文需要的当前变量通过提示组装或控制器提供。                                                                                                                                                      |
   | MVU 加载器、正文变量解析器、旧命令修复或重试脚本                                                                 | 删除旧运行机制                                               | 初值和业务校验按第1章转换，公式按第4章转换，用户操作按第2章转换。                                                                                                                                                       |
   | 源插件安装说明、编辑器专用标记或平台元数据                                                                       | 删除无目标消费者的部分                                       | 保留运行引用需要的身份信息及含有角色事实、玩法要求的内容。                                                                                                                                                              |
   | 禁用且没有脚本、提示或初始化入口读取的内容                                                                       | 删除退出运行的内容                                           | 明确被读取的禁用条目按第1、3章转换；判断同时覆盖脚本库与显式引用。                                                                                                                                                      |
   | 重复内容或空内容                                                                                                 | 删除没有有效内容，或已由同一消费者在相同条件下读取的重复部分 | 同文但触发条件或消费者不同的内容分别判断。                                                                                                                                                                              |
