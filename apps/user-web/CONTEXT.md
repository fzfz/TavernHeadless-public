# 用户演绎领域

## 1. 身份术语

1. **用户账号**：使用者登录用户 Web 的身份，也是其个人数据的归属主体。
2. **演绎人格**：用户为参与故事创建的人物资料，包含故事中的姓名和完整人设描述。已有接口文档中的“用户卡”和“演绎人设”对应此概念。
3. **默认人格**：用户指定的、开始新演绎时优先选中的演绎人格。

## 2. 会话术语

1. **演绎会话**：用户选择角色卡、演绎人格和开场后建立的一段故事，包含该故事的对话记录与状态。
2. **人格快照**：演绎会话创建时保存的所选演绎人格资料，用于确定该会话中用户扮演的人物。
