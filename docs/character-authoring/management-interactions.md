# 管理端交互与发布控制

## 角色切换

管理端左侧的角色应用下拉框用于切换当前角色。配置修订编号表示已保存的草稿修订，发布记录单独标记当前启用的版本。切换角色或新建角色时，页面会提示确认丢弃尚未保存的配置和资源编辑；取消后保留原来的编辑内容。

## 当前发布版本

`GET /role-releases?active_only=true` 返回各角色当前启用的发布版本。`latest_per_character=true` 仍按创建时间筛选最新版本；恢复历史版本后，两种查询可以返回不同结果。

管理端通过 `PUT /role-releases/:id/publication` 提交 `{ "active": true }`，将指定版本设为该账号下同一角色的新对话入口。提交 `{ "active": false }` 停止该版本的发布。每个账号的每个角色最多启用一个版本；停止已停用的历史版本不会影响当前启用版本。

发布新的角色版本会同时启用该版本。`POST /role-releases/:id/sessions` 只接受当前启用版本；版本已经停用时返回 `409 ROLE_RELEASE_INACTIVE`。已有会话继续使用创建时固定的配置。

数据库迁移 `0096_role_publication.sql` 在 `role_release` 表中增加 `is_active`，并设置每个账号、每个角色最多一个启用版本的索引。迁移时，每个角色原有的最新发布记录成为启用版本。发布快照的内容保持原样。

## 提示词预览

生成详情页的“按当前会话配置预览提示词”接收一条新的演绎消息，通过 `POST /sessions/:id/respond/dry-run` 展示消息、组装信息、提示词快照和运行追踪。请求可以传入 `branch_id`；省略时使用 `main`。预览读取所选分支的历史，不调用真实模型生成回复。

## 资源测试与 Agent 管理

正则编辑器使用当前编辑内容进行规则测试，允许选择执行位置、通道、消息深度和宏变量。测试结果列出输出文本、候选规则、匹配规则和跳过原因。

模型配置编辑器提供获取模型列表和测试连接。用户点击这些按钮后，服务端会访问所填供应商；连接测试可能产生模型调用费用。已保存配置的凭证留空时，测试使用服务端保存的凭证。

工作区 Agent 类型定义可供项目复用的 Agent 配置，包括运行作用域、模型及事件订阅。项目 Agent 将这些类型绑定到具体项目，并保存该绑定的运行配置。

工作区 Agent 类型支持创建、编辑、启用和停用。项目 Agent 支持绑定类型、编辑配置、启用、停用和手动运行。工作区与项目选择来自接口返回的数据，操作结果按对应对象刷新。
