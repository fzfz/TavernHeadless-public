# 阶段 6：用户 Web 视觉设计

## 1. 色彩系统

### 1.1 视觉方向与变量来源

1. 宿主界面采用温暖的纸色背景、墨绿色主操作与清晰的无衬线文字，延续[产品背景第 7 节](phase1-context.md)的阅读方向。页面以标题、正文与辅助信息建立层级，角色封面承担故事辨认。
2. [phase6-tokens.json](phase6-tokens.json)维护全部设计变量值；[阶段 5 第 3 节](phase5-components.md)提供变量用途与数值投影。本文规定变量组合和视觉用法。[视觉样式板](phase6-style-tile.html)直接读取该配置，展示浅色与深色样本。
3. 修改变量后运行 `node docs/ixd/user-web/phase6-sync.mjs`，同步阶段 5 数值表并生成[对比度结果](phase6-contrast.json)。阶段 7 的两套原型从同一配置派生样式。

### 1.2 配色用途

| 色彩组   | 变量                                            | 视觉用途                                                 |
| -------- | ----------------------------------------------- | -------------------------------------------------------- |
| 主色     | `--color-primary` 及 hover、pressed、on-primary | 页面主要提交、链接与当前导航；同一任务区域突出一个主操作 |
| 成功     | `--color-success`                               | 已确认保存或完成的文字与图标                             |
| 待处理   | `--color-warning`                               | 结果待确认、部分完成及可处理原因                         |
| 失败     | `--color-error`                                 | 字段错误与请求失败                                       |
| 删除     | `--color-danger` 及 hover、pressed、on-danger   | 删除确认中的执行操作                                     |
| 信息     | `--color-info`                                  | 读取和运行状态                                           |
| 中性层级 | text、bg、border、divider 变量                  | 阅读内容、表面分层和控件边界                             |

1. 大面积背景使用 bg-page，卡片、输入框和覆盖层使用 bg-surface。主色集中于操作与选中标记，功能色同时配有状态文字或形状。
2. 主按钮采用实色填充；次要按钮采用表面色与控件边框；文字按钮保留操作目标尺寸。链接使用主色与下划线。选中项采用 bg-selected、border-selected 和选择标记。
3. 可编辑字段及选择标记使用 border；卡片边界和普通分隔使用 divider。页面背景与卡片表面采用纯色，角色图像保留自身色彩。

### 1.3 可读性与对比度

1. 本设计对正文、辅助文字、占位文字和按钮文字统一采用至少 4.5:1 的目标；可辨认控件边界与焦点至少达到 3:1。依据分别为 [W3C 文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)与[非文本对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。
2. 允许的组合由配置生成的对比度结果逐项记录：文字与功能色可用于页面、表面、悬停、按下和选中背景；填色按钮使用对应的 on-primary 或 on-danger；禁用文字使用 bg-disabled。掩膜仅覆盖非活动背景，正文置于不透明表面。
3. 当前 124 组配色计算通过：文字组合最低为 4.55:1，控件组合最低为 3.19:1；判断使用未舍入值。该结果覆盖宿主变量组合。真实页面中的叠层、图片文字、焦点遮挡与角色内容按各自渲染结果验收。

## 2. 字体系统

### 2.1 字体与平台降级

1. 中文采用本机无衬线字体：macOS 优先 PingFang SC、Hiragino Sans GB，Windows 优先 Microsoft YaHei、SimHei，其余平台沿用配置中的 CJK 与通用字体降级。英文和数字采用系统界面字体，代码采用本机等宽字体；完整字体链以阶段 5 第 3.3 节为准。
2. 字体使用已有系统资源。两端共享字号与行高，主标题与条目标题通过字重和间距区分。角色 Runtime 内的标题、正文及装饰字体由角色定义。

### 2.2 八种文本样式

1. 下表通过变量组合定义用途；字号、行高与字重数值统一读取阶段 5 第 3.3 节。

| 文本样式   | 字号／行高变量后缀 | 字重变量后缀 | 颜色           | 使用示例                                    |
| ---------- | ------------------ | ------------ | -------------- | ------------------------------------------- |
| 页面标题   | title / title      | emphasis     | text-primary   | 演绎人格                                    |
| 区块标题   | section / section  | emphasis     | text-primary   | 选择本次人格                                |
| 条目标题   | card / card        | emphasis     | text-primary   | 裴修远                                      |
| 阅读正文   | body / body        | body         | text-primary   | 人格描述、开场与对话                        |
| 控件文字   | body / control     | emphasis     | 随控件表面     | 保存人格                                    |
| 字段标签   | meta / meta        | emphasis     | text-primary   | 人格姓名                                    |
| 辅助信息   | meta / meta        | body         | text-secondary | 更新时间、状态说明                          |
| 代码与序号 | meta / control     | body         | text-primary   | 代码块采用 code 字体；候选序号采用 num 字体 |

### 2.3 阅读与截断

1. 默认聊天外层采用 size-reading-max，正文列采用 size-prose-max；容器较窄时正文随容器收缩。正文段间距采用 space-lg，中英文混排沿用字体自然字距，数字排版采用阶段 5 第 3.3 节。
2. 列表摘要最多显示三行，标题最多显示两行，并提供对应详情入口。人格完整描述、开场全文、删除影响范围、错误与对话正文按内容完整排版。导航文字和操作文案换行后增高。
3. 引用使用 border-selected 左侧线与 space-md 内边距；代码使用 bg-hover 与 code 字体。正文强调采用 emphasis 字重，说话者名称与正文分行排列。

## 3. 图标系统

### 3.1 图形语言与来源

1. 图标采用线性轮廓、圆端点与圆连接。绘制坐标为 24 × 24，显示线宽采用 icon-stroke-width；尺寸变化时保持显示线宽。轮廓在网格内留出边缘，圆形与方形按视觉重量对齐。
2. 图标统一来自[共享图标模块](prototype/icons.mjs)的 `icons` 定义；图形通过 currentColor 取得所在控件颜色。
3. 操作图标的可访问名称、焦点和触控目标采用阶段 5 第 4.1、6.3 节。当前导航保留文字，并同时显示选中背景与标记。

### 3.2 图标用途与尺寸

| 场景                   | 图标变量        | 外层目标        | 图形映射                                                             |
| ---------------------- | --------------- | --------------- | -------------------------------------------------------------------- |
| 桌面侧栏与手机底栏     | size-icon       | size-target-min | compass 角色广场、history 历史、人物资料卡 演绎人格、person 用户中心 |
| 返回、关闭、更多与设置 | size-icon       | size-target-min | left、close、横向三点、settings                                      |
| 表单内部操作           | size-icon       | size-target-min | search、close、眼睛显隐                                              |
| 消息操作               | size-icon       | size-target-min | send、stop、refresh、branch、edit、trash                             |
| 状态及菜单前缀         | size-icon-small | 随所属控件      | 勾、信息圆圈、警示三角、错误圆圈                                     |

1. 人物资料卡、三点、眼睛与状态标记按第 3.1 节的同一网格补齐。纯图形补充项只服务已有操作与反馈，其文字含义由所属页面规格提供。

## 4. 插图与角色图像

### 4.1 辅助图形

1. 空态采用单个线性辅助图形，尺寸使用 size-state-art；颜色使用 text-secondary，置于标题上方。图形、标题、说明与操作之间采用 space-lg。具体文案引用相应页面规格。

| 场景           | 图形           | 文案与操作来源                |
| -------------- | -------------- | ----------------------------- |
| 角色集合为空   | 展开的书       | P01／P02 的集合空态           |
| 搜索无结果     | 放大镜         | P01／P02、P15／P16 的搜索空态 |
| 尚未创建人格   | 人物轮廓       | P09／P10、P13／P14 的创建入口 |
| 历史为空       | 时钟轮廓       | P15／P16 的历史空态           |
| 读取失败       | 信息圆圈       | 当前区域的 U06 反馈           |
| 页面无法访问   | 文档轮廓与问号 | P22 的原因与返回入口          |
| 局部或全部成功 | 状态勾         | 发起操作位置的确认文字        |

2. 图形可由第 3 节图标组合生成 SVG；缺失图形时标题、说明与操作保持原位置和可用性。

### 4.2 角色封面与媒体

1. 角色列表的图像容器采用宽高比 3:4；图片完整放入容器，空余区域填充 bg-hover。详情页保留原始比例，图像最大宽度受所在列约束。角色名称与摘要位于图像外的表面区。
2. 小型角色摘要使用等边缩略图，按完整图像适配。资源缺失或读取失败使用 U05 的替代文本与名称。角色内容中的场景图、立绘和背景采用角色资源及其 Runtime 布局。
3. 浅色与深色均保留图像原色；文字置于独立的不透明表面。插图资产范围采用第 4.1 节，角色媒体从实际角色资源取得。

## 5. 阴影与层级

| 表面                   | 阴影变量       | 边界与主题处理                                  |
| ---------------------- | -------------- | ----------------------------------------------- |
| 页面、角色卡与普通条目 | 无投影         | 卡片使用 divider，交互控件使用 border           |
| 操作菜单与提示         | shadow-surface | bg-surface 与 divider；深色读取对应 shadow 颜色 |
| 宿主对话框与手机面板   | shadow-overlay | bg-surface 与 divider；背后使用 bg-mask         |

1. 阴影几何值、颜色和叠放序号采用阶段 5 第 3.2、3.5 节。深色通过表面颜色与边界保持轮廓；阴影用于补充浮起感。
2. 角色区域的层级由 Runtime 布局组织；宿主覆盖层按阶段 5 第 4.8 节管理活动表面。

## 6. 圆角系统

1. 圆角数值与组件映射采用阶段 5 第 3.5 节。图片仅在所属圆角容器边缘裁切容器外区域；文字区与内容区共享外轮廓。手机面板使用上侧圆角，贴近浏览器边缘的一侧保持平直。
2. 焦点轮廓沿所属控件外形呈现，留出 space-focus-offset，宽度采用 border-focus-width。

## 7. 间距与栅格

### 7.1 栅格分配

1. 分界宽度、侧栏和内容上限采用阶段 5 第 6.1、3.4 节。下表的栏数用于对齐；任务的单列或多列组织由第 8 节指定。

| 浏览器区间                   | 对齐栅格 | 外边距／列间距     | 内容组织                                 |
| ---------------------------- | -------- | ------------------ | ---------------------------------------- |
| 手机，小于 tablet            | 4 栏     | space-lg／space-lg | 内容占满可用列，主导航位于底部           |
| 平板，tablet 至 desktop 之前 | 8 栏     | space-xl／space-lg | 沿用手机任务结构，表单居中               |
| 桌面，desktop 至 wide 之前   | 12 栏    | space-xl／space-lg | 侧栏之外的内容按任务分列                 |
| 宽屏，wide 及以上            | 12 栏    | space-xl／space-lg | 内容达到 size-content-max 后增加外侧留白 |

2. 页面标题与主要内容之间采用 space-xl，独立区块之间采用 space-xxl；同一字段的标签与输入之间采用 space-sm。卡片内边距、列表间距和独立操作间距采用阶段 5 中各组件规定。
3. 桌面角色网格按 size-card-min 和可用宽度确定列数；手机角色列表保持单列。阅读、表单与覆盖层分别采用自己的宽度上限。

### 7.2 导航与操作高度

1. 桌面顶栏采用 size-nav-desktop，手机顶栏采用 size-nav-mobile，手机主导航采用 size-nav-bottom，并额外保留浏览器安全区域。这些值均为最小高度，标题与标签换行后增高。
2. 主要提交采用 size-control-large，其他独立操作采用 size-control。页面高度由浏览器可用空间决定，短视口中的操作布局遵循阶段 5 第 6.2 节。

## 8. 页面类型视觉标注与例外

### 8.1 标注阅读方式

1. 页面类型来自[阶段 2 第 6 节](phase2-architecture.md)。本节覆盖其 17 类已承载类型；部分类型是页内区域或状态。每项同时标注手机与桌面，使用相同的组件与视觉变量。
2. 表中的“站点表面”指 bg-page 上的 bg-surface 内容区；“标准卡片”指 radius-surface、divider 边界和组件内边距；“主操作”指第 7.2 节的主要提交。站点顶栏、主导航尺寸与内容起始间距统一采用第 7 节。

### 8.4 通用聊天的视觉呈现

1. 通用聊天采用纵向阅读列，角色消息以说话者标签和正文排列，用户消息增加 bg-selected 表面与用户当前绑定的人格姓名标签。消息组间距采用 space-xl，正文行宽采用第 2.3 节。
2. 消息操作置于对应消息底部，候选序号的数字排版采用阶段 5 第 3.3 节；编辑模式在原消息位置显示 U11。生成状态、保存状态和结果待确认沿用对应文字标签，颜色采用第 1.2 节。
3. 角色挂载通用聊天时，聊天根节点使用不透明的宿主表面并显式取得主题变量。角色背景、插画、剧情面板与角色按钮按 Runtime 自身布局呈现；职责边界采用阶段 5 的 D10—D13。

## 9. 深色模式与高对比度

### 9.1 主题策略

1. 两端宿主界面跟随浏览器的系统配色偏好，并响应偏好变化。主题由浏览器环境决定。样式板的切换按钮仅用于查看两套视觉样本。
2. 深色的页面、表面、文字、主色、控件状态、掩膜与阴影使用阶段 5 第 3.2 节的完整映射。背景使用深灰绿，文字使用浅灰，主操作改用浅绿色表面与深色文字。
3. 图片处理采用第 4.2 节。主题变化保留当前布局、阅读位置与焦点；宿主主题对角色内容的作用范围采用第 8.4 节。

### 9.2 浏览器强制颜色

1. Windows 高对比度等环境启用 `forced-colors` 时，宿主表面、文字、链接与选择分别采用浏览器 Canvas、CanvasText、LinkText、Highlight 和 HighlightText；控件保留实体边框与焦点轮廓。依据见 [MDN 强制颜色说明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/forced-colors)。
2. 选中、错误、运行与禁用状态继续通过文字、标记和原生语义表达。SVG 操作图标使用 currentColor，图像继续提供文字替代。

## 10. 动效视觉

### 10.1 动效用途

1. 选中与按下反馈在交互发生时开始；文字反馈立即显示。持续加载使用明确的读取或运行文字，动效只补充变化过程。
2. 桌面页面以淡入衔接，手机子页进入以轻微位移表达层级；正文和运行状态持续可读。角色资源读取时保留已确定的容器位置。
3. 减少动态效果的处理采用阶段 5 第 3.6 节。主题切换即时更新颜色；流式文字按实际到达顺序出现。

### 10.2 动效参数与呈现

1. 时长与缓动数值采用阶段 5 第 3.6 节；位移使用已有间距变量。以下规则覆盖宿主组件，具体触发、中断和恢复条件采用对应页面规格。

| 场景                 | 时长变量                 | 视觉变化                                           |
| -------------------- | ------------------------ | -------------------------------------------------- |
| 控件悬停、按下与选择 | motion-duration-feedback | 表面色和边框色过渡；焦点轮廓立即显示               |
| 桌面页面进入         | motion-duration-page     | 正文透明度由 0 到 1，导航保持稳定                  |
| 手机子页进入         | motion-duration-page     | 正文从 space-sm 的横向偏移回到原位，同时淡入       |
| 对话框与手机面板     | motion-duration-overlay  | 对话框淡入；手机面板从 space-lg 的纵向偏移回到原位 |
| 用户触发阅读定位     | motion-duration-scroll   | 滚动到指定锚点；跟随生成使用页面规定的滚动策略     |

2. 所有过渡采用 motion-easing-standard。再次导航或关闭时按当前状态结束对应过渡；操作可用性由组件状态决定。
