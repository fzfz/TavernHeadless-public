# P12：编辑人格（桌面与手机 Web）

## 1. 页面概述

1. 本页属于演绎人格 L2，由 P09／P10 打开指定人格。用户阅读或修改该人格的姓名与完整描述，成功后返回人格列表。
2. 字段及归属采用 [P11 第 1 节](page-P11.md)。修改对已有会话的影响统一采用需求规格第 3 节第 7 项。

## 2. 页面布局

```text
返回人格列表 │ 编辑演绎人格
人格姓名（已有值）
完整人设描述（已有值）
使用范围说明 · 读取或保存反馈
取消 │ 保存修改
```

1. 双端页面外框、输入区域及键盘布局采用 P11 第 2 节。字段附近说明“修改后的资料用于之后开始的演绎”，便于用户判断本次修改用途。

## 3. 组件清单

| 编号 | 组件           | 类型           | 操作                     |
| ---- | -------------- | -------------- | ------------------------ |
| C01  | 返回与取消     | 导航或按钮     | 回 P09／P10              |
| C02  | 人格字段       | 单行与多行输入 | 阅读或修改姓名和描述     |
| C03  | 保存修改       | 按钮           | 更新当前人格             |
| C04  | 结果与变化提示 | 状态及按钮     | 重读目标、核对或确认草稿 |

## 4. 交互行为详述

1. **C02**：读取成功后填入完整保存值。字段校验、文本编辑、输入法和快捷键采用 P11 第 4 节；没有改动时保存按钮不可用，说明“资料尚未修改”。
2. **C03**：提交明确的人格目标；保存中固定本次内容，结果确认后回列表并显示更新后的条目。失败保留草稿，结果待确认按 S02 读取同一目标。
3. **C01**：有未保存修改时，离开选项采用 P11 第 4 节 C01；无修改直接返回。保存草稿以当前人格标识区分。
4. **C04**：恢复页面时发现已保存资料变化，显示当前保存值与本地草稿，提供“继续编辑草稿”和“使用已保存资料”。用户重新确认后才提交；后端明确返回冲突时使用同一处理。
5. 目标已删除或失去访问权限时，显示 P22 的对应结果；本地未提交内容仍按所属账号的草稿保留规则处理。重新读取失败保留已有可读内容与重试入口。

## 5. 页面状态流转

| 状态             | 呈现与后续                 |
| ---------------- | -------------------------- |
| 读取中           | 字段加载反馈，保存不可用   |
| 已读取／未修改   | 完整资料，可继续编辑或返回 |
| 已修改／校验失败 | 草稿与保存、取消或错误     |
| 保存中／待确认   | 进度或核对同一目标         |
| 资料已变化       | 当前值与草稿，用户选择处理 |
| 读取或保存失败   | 保留内容及恢复入口         |
| 资源失效         | 按 S01 转 P22              |

## 6. 动效说明

1. 表单反馈采用 P11 第 6 节 token。资料变化提示在字段上方展开，保留用户光标及阅读位置；减少动态效果时直接呈现。

## 7. 数据策略

1. 目标读取与更新均使用当前账号及人格标识。进入页面、恢复可见和保存前核对当前目标；服务端版本或冲突能力按实际接口使用，更新竞争的接入结论须以联调结果确认。
2. 草稿持久范围采用 P11 第 7 节，并增加人格标识区分；保存成功后清理该草稿。原保存内容作为修改比较依据，资料变化按 C04 处理。
3. 离线可继续编辑已读资料；连接恢复后核对目标与已发出的保存操作。人格快照的处理引用第 1 节采用的需求规则。

## 8. 适配说明

1. 文本输入、触控、软键盘与辅助技术采用 P11 第 8 节。完整描述始终可阅读，变化提示较长时使用文档滚动。
2. 双端返回后定位原人格条目；当前值与草稿各自使用明确标题，读屏可以区分两份内容。视觉验收采用目录说明第 1 节。

## 9. 交互走查

| 验收项                   | 依据                 |
| ------------------------ | -------------------- |
| 指定目标及完整资料       | 第 1、4 节           |
| 未修改、校验与保存反馈   | 第 4、5 节           |
| 取消、刷新与草稿恢复     | 第 4、7 节           |
| 资料变化、删除及权限失效 | 第 4 节 C04、第 7 节 |
| 更新用途及已有会话规则   | 第 1、2 节           |
| 长文、双端输入及读屏     | 第 8 节              |

## 10. 特定场景微交互说明

1. **资料变化提示**：行为采用第 4 节 C04。提示标题先说明哪份内容已保存，草稿区域保留当前输入位置；用户选择后将焦点移至对应编辑字段。
2. 使用第 6 节 token，声音与振动关闭。
