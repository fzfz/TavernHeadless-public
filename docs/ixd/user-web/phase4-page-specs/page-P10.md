# P10：演绎人格（手机 Web）

## 1. 页面概述

1. 本页属于演绎人格 L1，由手机主导航或 P08 进入；任务、归属及行为采用 [P09](page-P09.md)。创建、编辑和删除目标分别为 P11、P12、P21。

## 2. 页面布局

```text
演绎人格 · 创建人格
默认选择与读取反馈
单列人格卡
  姓名 · 默认标识
  描述摘要
  查看与编辑 · 设为默认 · 删除
加载更多
底部主导航
```

1. 正文纵向滚动，条目内的操作可换行；底部主导航使用阶段 2 的结构并避开安全区域。
2. 创建入口放在页首，空集合时在正文提供同一入口；长描述在 P12 阅读。

## 3. 组件清单

| 编号 | 组件       | 位置       | 操作                   |
| ---- | ---------- | ---------- | ---------------------- |
| C01  | 创建人格   | 页首或空态 | 进入 P11               |
| C02  | 人格条目   | 正文       | 阅读摘要、进入 P12     |
| C03  | 默认操作   | 条目内     | 设为默认或读取当前标识 |
| C04  | 删除       | 条目内     | 打开 P21               |
| C05  | 加载与结果 | 对应区域   | 加载、重试或核对       |
| C06  | 主导航     | 底部       | 切换模块               |

## 4. 交互行为详述

1. 条目、默认、删除和反馈采用 P09 第 4 节。编辑、默认及删除均使用可见按钮，长按描述保留文本选择行为。
2. 从 P11、P12 返回后将新建或编辑的条目带入视口；返回时仍有待核对操作则先显示对应提示，再按结果定位。
3. 点击默认操作后，反馈位于该条目内，视口保持稳定。手机返回关闭删除弹层的行为采用 P21。

## 5. 页面状态流转

| 状态             | 手机呈现与操作           |
| ---------------- | ------------------------ |
| 加载／局部失败   | 各区域分别反馈，创建可达 |
| 有人格／空集合   | 条目列表或创建引导       |
| 默认保存／待确认 | 对应条目显示进度或核对   |
| 删除完成         | 更新条目位置或进入空态   |
| 后台恢复         | 重读身份、集合与默认记录 |

## 6. 动效说明

1. 默认及列表更新采用 P09 第 6 节 token。返回定位使用 `--motion-duration-scroll`、`--motion-easing-standard`；减少动态效果时直接定位。

## 7. 数据策略

1. 归属、分页与写入恢复采用 P09 第 7 节。手机后台恢复后先取得有效身份，再恢复个人集合与条目锚点。
2. 移动网络切换时保留成功读取的条目；加载更多失败在列表尾部重试，默认核对在其反馈区域进行。

## 8. 适配说明

1. 点击范围与相邻间距采用 `--size-target-min`、`--space-control-gap`。长姓名、默认标识及操作换行后仍属于同一条目。
2. 屏幕阅读和外接键盘沿用 P09 第 8 节；文字放大、横屏及浏览器工具栏变化时保持底部导航与正文可达。
3. 删除按钮和其他操作各自拥有独立点击区域，视觉实测采用目录说明第 1 节。

## 9. 交互走查

| 验收项                   | 依据            |
| ------------------------ | --------------- |
| 多个人格及可见操作       | 第 2—4 节       |
| 默认、删除及空集合       | 第 4、5 节、P09 |
| 创建和编辑后定位         | 第 4 节         |
| 分页、后台及账号归属     | 第 7 节         |
| 触控、长文本、键盘与读屏 | 第 8 节         |

## 10. 特定场景微交互说明

1. **返回目标条目**：行为采用第 4 节第 2 项。定位完成后条目的姓名与操作同时可见；用户开始滚动时停止自动定位。
2. 使用第 6 节滚动 token，声音与振动关闭。
