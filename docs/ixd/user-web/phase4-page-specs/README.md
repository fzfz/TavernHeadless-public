# 阶段 4：用户 Web 页面交互规格

## 1. 阅读方式

1. 页面编号及覆盖范围采用[阶段 2 第 2 节](../phase2-architecture.md)，任务路径采用[阶段 3](../phase3-userflows.md)。本文及页面文件规定页面交互；当前消费入口统一见[功能依据](../feature-basis.md)。
2. 桌面页定义该任务的共用交互，手机页引用对应规则并规定手机布局、触控和浏览器恢复行为。跨平台弹层在同一文件内分别说明两端适配。
3. 页面中的动效、焦点和触控尺寸采用命名 token 占位。变量定义与取值见[阶段 5 第 3 节](../phase5-components.md)；页面规格只规定使用目的。
4. 各页面规格第 9 节列出交互验收项及其规则位置。视觉数值与浏览器操作分别在阶段 6、7 验收；当前布局原型的实现情况见需求规格第 5 节。

1. 页面规格覆盖阶段 2 的全部 22 项，每项包含 10 个章节；7 组桌面与手机页面分别交付，8 项共用页面或弹层覆盖两端。
