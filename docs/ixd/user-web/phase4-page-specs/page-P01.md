# P01：角色广场（桌面 Web）

## 1. 页面概述

1. 本页是角色选择模块的 L1 页面，面向访客和登录用户。用户浏览角色、设置筛选条件，进入 P03 阅读详情或进入 P13 开始演绎。
2. 页面采用[阶段 3 第 5 节 F03](../phase3-userflows.md)。登录与返回采用该文档的 F01、S01；角色字段与筛选能力采用[功能依据](../feature-basis.md)。

## 2. 页面布局

1. 页面结构如下，站点导航采用[阶段 2 第 4.1 节](../phase2-architecture.md)。

```text
主导航侧栏 │ 页面顶栏 · 账号入口
           │ 角色广场
           │ 搜索输入 · 搜索按钮 · 分类选项 · 重置筛选
           │ 当前条件与结果范围
           │ 角色卡网格：封面、名称、简介、标签、作者、操作
           │ 加载更多／列表读取反馈
```

2. 主内容纵向滚动，筛选与结果相邻。角色卡列数随可用宽度变化；每张卡以名称、简介及进入角色的操作为主要信息。角色资源缺少作者或标签时省略对应行。

## 3. 组件清单

| 编号 | 组件               | 位置／类型           | 触发与结果                   |
| ---- | ------------------ | -------------------- | ---------------------------- |
| C01  | 站点导航及账号入口 | 侧栏、顶栏／导航     | 切换模块、登录或打开用户中心 |
| C02  | 角色搜索           | 页首／输入与按钮     | 提交关键词                   |
| C03  | 分类与重置         | 页首／单选与按钮     | 应用分类或恢复全部角色       |
| C04  | 结果范围           | 列表上方／状态文本   | 展示已应用条件及返回范围     |
| C05  | 角色卡             | 网格／文章与链接     | 查看详情或开始演绎           |
| C06  | 加载及恢复         | 列表底部或空态／按钮 | 加载更多、重试读取或清除条件 |

## 4. 交互行为详述

1. **C01**：当前导航项标记“角色广场”。访客账号入口进入 P05，已登录入口进入 P07；返回原目标采用 F01。侧栏中的个人资源入口按 S01 校验登录状态。
2. **C02**：输入支持粘贴、清除和输入法；点击搜索或组词结束后的 Enter 应用关键词。字段标签为“搜索角色”，提示说明可搜索名称、故事或标签。编辑中的文字与已应用条件分别保存，搜索成功后结果从首批开始。
3. **C03**：分类采用可用的分类词表，首项为“全部”；单选支持点击、方向键与空格。切换分类保留已应用关键词；“重置筛选”同时清空关键词并选择全部。存在已应用条件时提供重置入口。
4. **C04**：完整总数由查询返回时显示匹配数量；只有分页记录时显示“已加载 N 个角色”。读取新条件期间明确显示正在更新的条件，旧结果附带原条件说明，完成后替换。
5. **C05**：封面和名称进入 P03，“开始演绎”进入 P13；嵌套操作各自可聚焦。已知角色暂不可开始时，该按钮显示原因，详情入口仍按资源可访问性提供。访问时发现资源失效交 S01 处理。
6. **C06**：追加失败保留已加载角色；首批失败在结果区重试。确认无匹配时显示“没有符合条件的角色”与重置入口；公开集合为空时显示“暂无可浏览的角色”和重新读取入口。
7. 所有控件提供悬停、按下和焦点反馈。搜索完成播报结果范围，焦点留在发起控件；用户可通过“跳到角色列表”进入结果标题。

## 5. 页面状态流转

| 状态         | 条件                 | 呈现与后续操作                     |
| ------------ | -------------------- | ---------------------------------- |
| 首批加载     | 初次访问             | 结果区域加载反馈，导航可用         |
| 有结果       | 查询成功且非空       | 卡片与加载范围；可查看或开始       |
| 筛选更新     | 应用新条件           | 保留已读内容与其条件，展示读取状态 |
| 无匹配       | 条件查询确认为空     | 重置筛选或修改条件                 |
| 集合为空     | 全部角色查询确认为空 | 空态与重新读取                     |
| 追加中／失败 | 请求下一批           | 保留列表，底部反馈与重试           |
| 首批失败     | 查询失败             | 保留条件，提供重试                 |
| 离线         | 连接不可用           | 已取得角色可阅读；恢复后重读       |

## 6. 动效说明

1. 条件选中与请求反馈使用 `--motion-duration-feedback`、`--motion-easing-standard`。列表替换保持容器位置，追加数据保持已读卡片位置。
2. 减少动态效果偏好启用时直接替换状态；图片空间预留由组件布局确定，避免加载后推动相邻操作。

## 7. 数据策略

1. 查询以已应用关键词、分类及访问身份为范围，翻页沿用相同条件。页面仅呈现与当前已应用条件匹配的查询结果。
2. 服务端分页筛选与分类词表的消费入口见[功能依据第 2 节](../feature-basis.md#2-功能与数据来源)。分页查询覆盖完整可见集合，计数采用 C04 的规则。
3. 从 P03、P13 或登录返回时恢复已应用条件、输入草稿及已读卡片锚点，重新读取后定位仍存在的角色。角色消失时落到相邻条目或列表标题。
4. 角色图片按可见范围加载，失败时保留名称与文本信息。刷新或页面重新可见时重读当前条件；离线缓存只用于已取得内容的阅读。

## 8. 适配说明

1. 宽度缩窄或文字放大时筛选控件换行，卡片减少列数；名称换行，完整故事在 P03 阅读。手机独立布局见 [P02](page-P02.md)。
2. 搜索使用显式标签，分类使用单选语义，结果使用列表与文章语义。焦点顺序按导航、搜索、分类、角色及加载入口排列；错误关联发起控件。
3. 触屏桌面设备使用 `--size-target-min` 与 `--space-control-gap` 对应的操作范围。图像替代文本表达角色名称；相邻文本已提供名称时，装饰封面可使用空替代文本。对比度、焦点和主题实测采用目录说明第 1 节。

## 10. 特定场景微交互说明

1. **应用筛选**：行为采用第 4 节 C02—C04。选中标识先反馈，查询进度在结果标题附近呈现；返回数据时保留该标题位置。使用第 6 节 token。
2. 用户连续改变条件时，以最新已应用条件决定展示；声音与振动关闭。
