# P14：开始演绎（手机 Web）

## 1. 页面概述

1. 页面属于角色演绎 L2，入口为 P02、P04，成功后进入 P18。页面目标和任务规则引用 [P13 第 1 节](page-P13.md)，共用交互引用该文档第 4、5、7 节。

## 2. 页面布局

1. 手机使用独立子页顶栏及单列内容，结构如下。

```text
返回来源 │ 开始演绎
当前角色名称与摘要
演绎人格单选组 · 创建人格
所选人格完整描述
角色开场单选组
所选开场全文（展开／收起）
本次选择摘要
底部提交区：反馈 · 开始演绎
```

2. 正文统一纵向滚动。底部提交区位于浏览器可见区域底部，避开安全区域，并为最后一项内容保留空间。反馈过长、横屏或文字放大导致可见正文不足时，提交区回到文档流。
3. 手机子页导航采用阶段 2 第 4.1 节；创建人格进入 P11，由该页承载文本输入。创建成功返回后，页面定位到人格组；选择恢复采用 P13 第 4 节 C04。

## 3. 组件清单

| 编号 | 组件     | 手机位置         | 操作                         |
| ---- | -------- | ---------------- | ---------------------------- |
| C01  | 返回来源 | 顶栏             | 返回 P02 或 P04              |
| C02  | 当前角色 | 正文顶部         | 阅读名称及摘要               |
| C03  | 人格选择 | 正文第一组       | 点击单选，读取所选描述       |
| C04  | 创建人格 | 人格组尾部或空态 | 进入 P11                     |
| C05  | 开场选择 | 正文第二组       | 点击单选并更新预览           |
| C06  | 全文预览 | 开场组后         | 展开或收起长文               |
| C07  | 开始演绎 | 底部提交区       | 创建并打开 P18               |
| C08  | 请求反馈 | 对应区域或提交区 | 重试读取、核对结果、返回历史 |

## 4. 交互行为详述

1. C01—C08 的选择、提交与恢复规则引用 P13 第 4 节。点击单选条目的标签区域即可选择；正文复制和预览展开分别操作，避免一次点击同时选择与展开。
2. 选中人格或开场后，提交摘要立即同步。用户滚动阅读时保持当前视口；预览内容变化在对应标题下反馈，用户可继续向下阅读。
3. 用户点击不可提交的按钮附近提示时，可以读取缺少的选择项；提交校验发现失效项时，将其标题带入视口并提供可访问焦点，底部提交区保留其他有效选择的摘要。
4. 创建、核对和重试均具有按下反馈。操作入口使用常驻按钮，长按保持浏览器文本选择行为。手势返回与浏览器后退采用相同来源和选择恢复规则。

## 5. 页面状态流转

1. 业务状态沿用 P13 第 5 节，手机呈现差异如下。

| 状态                 | 手机呈现与操作                                         |
| -------------------- | ------------------------------------------------------ |
| 加载或局部失败       | 在各选择组原位置反馈；提交区显示等待原因               |
| 人格为空             | 第一组显示创建入口，已取得的开场继续可读               |
| 可选择               | 所选条目与底部摘要同时表达当前选择                     |
| 提交中               | 选项固定，底部显示创建进度；返回操作按 P13 第 7 节处理 |
| 明确失败             | 对应组显示原因，保留有效项并引导修正                   |
| 结果待确认           | 底部显示核对入口；可返回手机历史 P16                   |
| 已创建但会话加载失败 | 提供打开已创建会话的入口，目标仍为 P18                 |
| 身份或访问异常       | 按 S01 进入 P05 或 P22，返回后重新校验                 |
| 浏览器从后台恢复     | 保留视口与选择，重读资源及待核对结果                   |

## 6. 动效说明

1. 选择和展开使用 P13 第 6 节的反馈 token；提交区状态直接更新，避免因反馈文字变化遮住选择项。
2. 返回人格组或失效项时使用 `--motion-duration-scroll` 与 `--motion-easing-standard`；减少动态效果偏好启用时直接定位。

## 7. 数据策略

1. 请求归属、分页、选择缓存、资源失效和创建结果恢复引用 P13 第 7 节。列表加载更多时保留当前选择与滚动锚点，用户可继续读取已加载条目。
2. 页面进入后台后再恢复时，先核对当前账号与请求结果，再恢复可执行按钮。浏览器回收页面后从已保存目标重新读取；本地选择可恢复时回填，无法恢复时提示重新选择。
3. 已读取内容在离线时保持可读，底部说明连接状态。连接恢复后重新校验本次选择，再决定能否提交。

## 8. 适配说明

1. 横屏、窄屏、浏览器文字放大时保持单列。长姓名与开场标题换行；完整描述通过文档滚动阅读。安全区域与浏览器工具栏变化由可见视口布局处理。
2. 触控目标和相邻操作间距采用 `--size-target-min`、`--space-control-gap`；单选标签扩大点击范围，创建与展开按钮分别保留独立目标。
3. 屏幕阅读顺序与第 2 节一致。单选组、展开语义、错误关联和结果播报引用 P13 第 8 节；接入外接键盘时支持同等选择操作。
4. 本页使用选择控件；需要创建人格时跳转 P11。浏览器软键盘因辅助输入出现时，提交区随可见视口调整并保持焦点控件可见。对比度、字号及主题实际效果在阶段 6、7 验收。

## 10. 特定场景微交互说明

1. **创建人格后返回**：成功与取消的选择规则采用 P13 第 4 节 C04；返回位置采用本页第 2 节。定位完成后让所选标识与姓名同时进入视口，底部摘要使用相同姓名，方便用户核对。
2. 滚动使用第 6 节 token，减少动态效果时直接定位；用户开始滚动时停止页面的自动定位。声音与振动关闭。

3. 开场切换与提交反馈采用 P13 第 10 节；开场预览反馈位置采用本页第 4 节第 2 项，提交反馈位于底部提交区。
