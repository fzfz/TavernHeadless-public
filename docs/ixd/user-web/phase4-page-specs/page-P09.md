# P09：演绎人格（桌面 Web）

## 1. 页面概述

1. 本页属于演绎人格 L1，由主导航或 P07 进入。用户管理当前账号的人格集合；创建进入 P11，编辑进入 P12，删除进入 P21。
2. 任务采用[阶段 3 F02](../phase3-userflows.md)，归属、默认选择与快照规则统一采用[需求规格第 3 节](../user-web-requirements.md)。

## 2. 页面布局

```text
站点侧栏 │ 演绎人格 · 创建人格
         │ 默认选择与请求反馈
         │ 人格列表
         │ 姓名 · 默认标识 · 描述摘要
         │ 查看与编辑 · 设为默认 · 删除
         │ 加载更多／读取反馈
```

1. 主区域纵向滚动，每条人格的姓名、描述及操作保持一组。完整描述在 P12 阅读；列表摘要只用于区分条目。
2. 创建入口始终可达；空集合使用同一入口。默认标识附属于对应条目，跨页加载时由独立默认记录说明当前选择。

## 3. 组件清单

| 编号 | 组件       | 类型／位置     | 操作               |
| ---- | ---------- | -------------- | ------------------ |
| C01  | 创建人格   | 页首按钮       | 进入 P11           |
| C02  | 人格条目   | 列表           | 阅读姓名与描述摘要 |
| C03  | 查看与编辑 | 条目链接       | 进入 P12           |
| C04  | 默认选择   | 条目按钮与标识 | 设为默认并反馈结果 |
| C05  | 删除       | 条目按钮       | 打开 P21           |
| C06  | 加载与结果 | 状态与按钮     | 追加、重读或核对   |

## 4. 交互行为详述

1. **C01、C03**：创建携带本页返回目标，编辑携带所选人格标识。返回后重新读取对应条目及默认记录，并恢复条目位置；新建条目应出现在可读范围内。
2. **C04**：当前默认项显示“默认人格”，其他条目提供“设为默认”。点击后显示目标条目的保存反馈，当前已保存默认标识保留至成功确认；保存中其余默认操作等待，创建及阅读入口仍可用。
3. 默认保存成功后重读并更新唯一默认标识；明确失败展示原因并恢复可重试入口，结果待确认时提供“核对默认选择”。默认保存位置与跨设备能力按[功能依据](../feature-basis.md)接入验收。
4. **C05**：打开 [P21](page-P21.md)并传入人格目标；完成后的默认选择采用需求规格，列表重新读取相关结果。被删除条目的焦点处理采用 P21。
5. **C06**：首批失败保留创建入口与重试；分页失败保留已有条目。空集合提示“创建你的第一个演绎人格”，按钮进入 P11。默认读取失败只标记该项状态，已有条目仍可查看。
6. 条目操作分别聚焦并包含人格姓名的可访问说明。按钮具有悬停、按下、焦点反馈；保存结果使用礼貌播报，列表顺序保持读取返回的顺序。

## 5. 页面状态流转

| 状态             | 呈现与后续                     |
| ---------------- | ------------------------------ |
| 加载             | 人格与默认记录分别反馈         |
| 有人格           | 展示条目、已确认默认及操作     |
| 空集合           | 创建引导                       |
| 默认保存中       | 目标条目显示进度               |
| 默认失败／待确认 | 原选择及重试或核对             |
| 局部读取失败     | 成功数据可读，失败部分重试     |
| 删除完成         | 重读集合，按结果进入列表或空态 |
| 身份失效         | 按 S01 恢复访问                |

## 6. 动效说明

1. 默认标识、保存反馈与列表更新使用 `--motion-duration-feedback`、`--motion-easing-standard`。成功切换时两个相关条目的标识共同更新。
2. 减少动态效果时直接呈现；追加和删除后的阅读位置采用条目锚点。

## 7. 数据策略

1. 人格集合与默认记录按当前账号读取。列表采用实际分页方式提供“加载更多”，默认人格未在已加载页时读取其必要姓名与标识；显示的默认来自确认结果。
2. 创建、编辑、删除返回及页面恢复可见时重读集合和默认记录。目标被其他标签页删除时刷新对应条目；当前待核对操作采用 S02。
3. 本标签页保留列表锚点与已加载范围；账号切换采用 S01 的隔离规则。离线保留已取得资料供阅读，写操作等待连接后的资源核对。

## 8. 适配说明

1. 缩窄和文字放大时条目操作换行；长姓名及描述摘要有可读内容，完整描述入口保持可达。手机组织见 [P10](page-P10.md)。
2. 列表与条目使用语义结构，默认状态同时通过文本表达；键盘按创建、条目操作及加载顺序遍历。操作触控范围采用 `--size-target-min`。
3. 状态提示关联目标条目；视觉和浏览器验收范围采用目录说明第 1 节。

## 10. 特定场景微交互说明

1. **设为默认**：行为采用第 4 节 C04。保存反馈紧邻目标姓名，确认后的标识变化使用同一反馈节奏；焦点留在发起条目的对应控件。
2. 使用第 6 节 token，声音与振动关闭；减少动态效果时直接更新。失败恢复采用 C04。
