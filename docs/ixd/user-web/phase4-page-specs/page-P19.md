# P19：演绎设置（桌面与手机 Web）

## 1. 页面概述

1. 本弹层由 P17／P18 打开，沿用宿主页层级。用户查看当前角色和人格姓名，修改本次演绎标题；关闭后返回同一会话与分支。
2. 任务采用[阶段 3 F04](../phase3-userflows.md)，标题更新通过 S02 核对；完整人格快照的阅读目标为 P20。

## 2. 页面布局

```text
演绎设置 · 关闭
角色名称（只读）
本次人格姓名 · 查看完整人设
演绎标题
字段与保存反馈
取消 │ 保存标题
```

1. 桌面使用宿主居中对话框，手机使用底部对话框；键盘、大字或横屏导致空间不足时适应可用视口并允许正文滚动。
2. 操作区保持可达，背景会话保留阅读位置及输入草稿；角色 Runtime 在原会话生命周期中继续运行。

## 3. 组件清单

| 编号 | 组件           | 类型           | 操作               |
| ---- | -------------- | -------------- | ------------------ |
| C01  | 关闭与取消     | 按钮           | 回到会话           |
| C02  | 角色及人格     | 只读资料与链接 | 阅读姓名、打开 P20 |
| C03  | 演绎标题       | 单行输入       | 编辑当前标题       |
| C04  | 保存标题       | 按钮           | 提交更新           |
| C05  | 读取与保存反馈 | 状态与按钮     | 重读、核对或修正   |

## 4. 交互行为详述

1. **C02**：角色信息来自当前会话固定资源，人格姓名来自会话快照。打开 P20 时替换当前覆盖层并保留标题草稿，P20 关闭后回到本弹层。
2. **C03、C04**：读取后填入已保存标题，校验采用会话标题契约。未修改时保存不可用；Enter 在组词完成后提交，保存中固定内容并显示进度。成功后关闭弹层并更新宿主页标题；失败保留输入，待确认提供核对入口。
3. **C01**：无修改时关闭、取消、Esc、外部点击及手机返回均回会话；有未保存修改时提供“继续编辑”“保留草稿并关闭”“放弃修改”。已经发出的请求由宿主页继续核对。
4. **C05**：读取失败保留关闭和重试；重读发现标题变化时并列显示当前保存值与草稿，用户选择后重新确认。身份失效或会话不可访问时按 S01 处理。
5. 打开后聚焦标题或首个可操作控件，关闭后焦点回演绎设置按钮。按钮提供悬停、按下及焦点反馈，保存结果在宿主状态区域播报。

## 5. 页面状态流转

| 状态             | 呈现与后续               |
| ---------------- | ------------------------ |
| 读取中／失败     | 状态、关闭或重试         |
| 未修改           | 当前资料与不可提交的标题 |
| 已修改／校验失败 | 草稿及保存或字段错误     |
| 保存中／待确认   | 进度或核对入口           |
| 标题已变化       | 当前保存值与草稿         |
| 已保存           | 关闭并更新会话标题       |
| 访问失效         | 按 S01 恢复访问          |

## 6. 动效说明

1. 弹层使用 `--motion-duration-overlay`、`--motion-easing-standard`，字段反馈使用 `--motion-duration-feedback`。减少动态效果时直接呈现。
2. P19 与 P20 切换保留覆盖层位置，内部内容按目标更新；关闭恢复宿主阅读位置。

## 7. 数据策略

1. 按当前账号及会话读取标题与身份资料。标题草稿沿用 [P15 第 7 节](page-P15.md)的会话草稿归属，字段内容从该会话草稿恢复。
2. 写入结果采用 S02；弹层关闭及页面刷新后由宿主恢复核对。标题保存仅更新当前会话的标题；快照的使用规则引用需求规格第 3 节。
3. 页面再次可见时重读标题，变化按 C05 处理；离线保留草稿和已读资料，连接恢复后核对已发出的更新。

## 8. 适配说明

1. 弹层使用对话框语义，背景退出焦点顺序，Tab 在弹层内部遍历。P20 返回后焦点回查看人设入口；关闭后的目标采用第 4 节。
2. 手机标题聚焦时，字段、错误及保存操作可滚动到键盘上方。点击范围采用 `--size-target-min`；长角色和人格姓名换行。
3. 大字及横屏下操作可达，视觉与浏览器验收见目录说明第 1 节。

## 9. 交互走查

| 验收项                 | 依据             |
| ---------------------- | ---------------- |
| 会话身份来源与只读资料 | 第 4 节 C02      |
| 标题校验、保存和取消   | 第 4 节 C03、C04 |
| 人设弹层往返与草稿     | 第 4、7 节       |
| 待确认、关闭及页面恢复 | 第 5、7 节       |
| 焦点、软键盘和长姓名   | 第 8 节          |

## 10. 特定场景微交互说明

1. **查看人设再返回**：行为采用第 4 节 C02。内容切换保持覆盖层外框位置，返回时标题草稿仍在原字段内，反馈区域保持原位置。
2. 采用第 6 节 token，声音与振动关闭；焦点顺序引用第 8 节。
