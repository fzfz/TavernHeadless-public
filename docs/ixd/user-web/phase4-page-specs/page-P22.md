# P22：页面无法访问（桌面与手机 Web）

## 1. 页面概述

1. 本页为全局结果页面，由 S01 在未知地址、目标不存在或无权访问时进入。返回关系采用[阶段 2 第 4.2 节](../phase2-architecture.md)。
2. 网络与服务读取失败由原页面承载；登录身份失效由 F01 恢复。本页按确定的访问结果提供可达的返回目标。

## 2. 页面布局

```text
页面无法访问
具体原因
返回角色广场／人格列表／历史演绎
```

1. 双端使用独立结果布局，说明与主要返回操作相邻。桌面内容居于主要阅读区域，手机采用单列并避开安全区域；长文使用文档滚动。
2. 失败资源的操作入口随目标页面退出；当前结果页只承载原因与返回导航。

## 3. 组件清单

| 编号 | 组件     | 类型 | 操作             |
| ---- | -------- | ---- | ---------------- |
| C01  | 结果标题 | 标题 | 说明当前访问结果 |
| C02  | 原因说明 | 文本 | 阅读可理解的原因 |
| C03  | 返回入口 | 链接 | 打开对应可达列表 |

## 4. 交互行为详述

1. **C01、C02**：未知地址使用“没有找到这个页面”；角色、人格或会话已不存在时使用对应名称的说明；访问被拒绝时显示“当前账号无法访问此内容”。反馈依据实际访问结果，未知或不可读的目标名称采用资源类型表达。
2. **C03**：角色和未知地址返回角色广场，人格返回人格列表，会话返回历史演绎；桌面与手机目标按阶段 2 对应编号。个人列表访问需要登录时由 S01 处理。
3. 浏览器后退沿浏览器历史返回，页面主要按钮使用明确目标，避免返回同一失效资源。用户刷新当前地址时重新执行 S01；资源已恢复可访问则进入原目标。
4. 页面到达后焦点置于结果标题，返回链接提供悬停、按下及焦点反馈，Enter 激活。页面加载结果用标题和说明表达。

## 5. 页面状态流转

| 状态             | 条件             | 呈现与后续                   |
| ---------------- | ---------------- | ---------------------------- |
| 未知地址         | 路由无法识别     | 原因及返回广场               |
| 资源不存在       | 读取确认目标缺失 | 对应资源说明及所属列表       |
| 无访问权限       | 读取返回访问拒绝 | 当前账号的访问说明及所属列表 |
| 刷新核对         | 浏览器刷新       | S01 重新读取并决定目标       |
| 返回目标读取失败 | 列表查询失败     | 由目标列表呈现恢复入口       |

## 6. 动效说明

1. 页面到达使用 `--motion-duration-page`、`--motion-easing-standard`，链接反馈使用 `--motion-duration-feedback`。减少动态效果时直接呈现。

## 7. 数据策略

1. 本页接收原目标的资源类型和确定的错误类别，据此确定文案与返回页面。资源身份校验及数据读取由 S01 执行。
2. 账号切换后再次访问原地址时重新校验权限。浏览器刷新以当前服务返回结果为准，离线核对失败采用 S01 的读取失败状态。
3. 结果页面只使用可公开或当前账号有权取得的目标信息；此前表单和消息草稿仍归各自页面的账号与资源范围。

## 8. 适配说明

1. 长说明、大字及横屏保持标题和返回入口可见；移动端操作范围采用 `--size-target-min`、`--space-control-gap`。
2. 页面使用 `main`、单一主标题和明确链接名，读屏按结果、原因、返回顺序读取。键盘无需经过失效目标的原控件即可返回。
3. 焦点可见性、对比和主题实测采用目录说明第 1 节。

## 9. 交互走查

| 验收项                     | 依据         |
| -------------------------- | ------------ |
| 未知、缺失和拒绝的文案区别 | 第 4、5 节   |
| 各资源的返回路径           | 第 4 节 C03  |
| 网络失败和登录恢复归属     | 第 1 节、S01 |
| 刷新与账号变化后的重读     | 第 4、7 节   |
| 目标信息范围与草稿归属     | 第 7 节      |
| 键盘、触控、读屏及长文     | 第 8 节      |

## 10. 特定场景微交互说明

1. **返回所属列表**：行为采用第 4 节 C03。链接按下反馈后，列表的读取反馈在目标页面呈现；结果页标题保持到导航完成。
2. 使用第 6 节 token，声音与振动关闭；加载失败由目标列表的状态规则处理。
