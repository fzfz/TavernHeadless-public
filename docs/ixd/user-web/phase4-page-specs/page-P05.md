# P05：登录（桌面与手机 Web）

## 1. 页面概述

1. 本页为独立账号页面，入口为访客账号入口、受保护目标及 P06。任务采用[阶段 3 第 3 节 F01](../phase3-userflows.md)，成功后通过 S01 打开原目标。
2. 邮箱密码身份服务的接入状态采用[功能依据](../feature-basis.md)。模拟原型在表单附近显示“模拟账号流程”和演示账号入口；实际登录表单由接入后的身份服务处理。

## 2. 页面布局

```text
桌面：返回来源 │ 产品名称与说明 │ 登录表单
手机：返回来源
      登录
      邮箱
      密码 · 显示／隐藏
      错误或提交反馈
      登录并继续
      注册账号
```

1. 桌面表单为单列，说明区域可在可用宽度不足时收起；手机使用完整单列文档流。页面不使用个人模块导航，返回入口采用阶段 2 第 4.2 节。
2. 表单及结果按相同顺序阅读，手机键盘展开时允许整页滚动，提交与错误保持可达。

## 3. 组件清单

| 编号 | 组件         | 类型           | 操作                             |
| ---- | ------------ | -------------- | -------------------------------- |
| C01  | 返回来源     | 导航           | 回公开来源或角色广场             |
| C02  | 邮箱         | 单行输入       | 填写登录邮箱                     |
| C03  | 密码与可见性 | 密码输入及按钮 | 输入、显示或隐藏密码             |
| C04  | 登录并继续   | 提交按钮       | 建立登录身份                     |
| C05  | 注册账号     | 链接           | 进入 P06                         |
| C06  | 表单反馈     | 状态区域       | 显示校验、请求原因或身份核对入口 |

## 4. 交互行为详述

1. **C02、C03**：邮箱标签明确，密码允许粘贴和密码管理器填充。邮箱使用邮箱输入语义与 `username` 自动填充，密码使用 `current-password`；密码可见性按钮说明当前动作并保留输入位置。
2. 提交时校验必填与邮箱格式，其余凭据规则采用身份服务契约；校验失败聚焦首个错误字段。表单 Enter 在输入法组词结束后提交；点击与键盘提交执行同一行为。
3. **C04、C06**：提交后显示“正在登录…”，固定本次凭据并锁定重复提交。成功身份确认后调用 S01；凭据失败显示“邮箱或密码不正确”，网络失败显示“连接失败，请重试”。失败后本页保留可修正输入。
4. 登录请求结果不明时先核对当前身份；已建立身份则恢复原目标，确认未登录则恢复表单，身份核对失败则保留“重新核对登录状态”入口和返回操作。
5. **C05**：进入 P06 时保留原目标及已填写邮箱；P06 返回后恢复邮箱并聚焦密码。**C01** 返回公开来源，直接访问时回角色广场；离开账号页时清理本页密码。
6. 已登录用户访问本页时先核对身份，有有效原目标则通过 S01 打开，否则进入 P07／P08。登录期间仍可返回公开页面；身份响应由账号访问流程核对，页面只接收当前有效登录请求的结果。
7. 所有按钮具有悬停、按下和焦点反馈。字段错误关联输入，提交错误在反馈区播报；密码显隐按钮使用明确可访问名称。

## 5. 页面状态流转

| 状态       | 触发           | 呈现与操作                 |
| ---------- | -------------- | -------------------------- |
| 可填写     | 身份确认未登录 | 输入、返回或注册           |
| 校验失败   | 字段不满足契约 | 字段原因与保留输入         |
| 提交中     | 登录已发出     | 固定凭据及进度，返回仍可用 |
| 凭据失败   | 身份服务拒绝   | 原因与可修正表单           |
| 身份待核对 | 响应缺失       | 核对入口与返回             |
| 已登录     | 身份有效       | S01 打开原目标             |
| 读取失败   | 身份核对失败   | 重试或回公开页面           |

## 6. 动效说明

1. 字段反馈、密码显隐及按钮状态使用 `--motion-duration-feedback`、`--motion-easing-standard`。错误区域保留位置，避免出现错误后推动用户正在操作的字段。
2. 减少动态效果时直接呈现；登录完成的页面切换使用 `--motion-duration-page`。

## 7. 数据策略

1. 当前页面内存保留密码至成功、离开或刷新；邮箱与站内原目标可在当前标签页恢复。浏览器刷新后重新读取身份，密码由用户或密码管理器重新填写。
2. 身份变化后清理上一账号的个人页面数据，并按 S01 重新校验目标归属。认证失败、资源无权限及连接失败分别处理。
3. 离线时保留本页输入并说明连接状态，连接恢复后允许重新核对身份。身份服务的账号映射、凭据管理及结果证据统一按功能依据接入验收。

## 8. 适配说明

1. 手机邮箱使用合适键盘，密码字段保持密码输入语义。软键盘和浏览器工具栏变化时，焦点字段及其错误可滚动进入视口；表单按文档顺序遍历。
2. 窄屏和大字使用单列，所有标签保持可见。触控范围与间距采用 `--size-target-min`、`--space-control-gap`；显示密码按钮与输入字段分别聚焦。
3. 错误文本提供具体修正方向；视觉对比、焦点及主题验收见目录说明第 1 节。

## 10. 特定场景微交互说明

1. **密码显隐**：行为采用第 4 节 C03。按钮文字切换时保留输入宽度与光标位置；焦点仍在发起控件。
2. **登录提交**：行为采用 C04、C06，进度与错误使用同一反馈区域。采用第 6 节 token，声音与振动关闭；减少动态效果时直接更新。
