# P11：创建人格（桌面与手机 Web）

## 1. 页面概述

1. 本页从 P09／P10 进入时为 L2，从 P13／P14 进入时为 L3。任务采用[阶段 3 F02](../phase3-userflows.md)，成功和取消均返回发起页面。
2. 字段与归属采用[需求规格第 3 节](../user-web-requirements.md)。本页只编辑人格姓名和完整描述。

## 2. 页面布局

```text
返回来源 │ 创建演绎人格
人格姓名
完整人设描述（多行）
字段说明与保存反馈
取消 │ 保存人格
```

1. 双端使用单列表单。桌面保留来源所属模块的站点导航；手机使用子页返回结构。描述字段随内容增高；达到可见视口扣除页首、字段标签与保存区后的剩余高度时，字段内部开始滚动。页面其余内容通过文档滚动到达。
2. 保存区位于表单末尾；手机软键盘展开时输入、错误与操作可滚动进入可见视口。

## 3. 组件清单

| 编号 | 组件         | 类型       | 操作               |
| ---- | ------------ | ---------- | ------------------ |
| C01  | 返回与取消   | 导航或按钮 | 返回来源           |
| C02  | 人格姓名     | 单行输入   | 输入故事中的姓名   |
| C03  | 完整人设描述 | 多行文本   | 描述本次人物资料   |
| C04  | 保存人格     | 提交       | 创建当前账号的人格 |
| C05  | 保存反馈     | 状态及按钮 | 修正、重试或核对   |

## 4. 交互行为详述

1. **C02、C03**：姓名和描述必填，空白输入在提交时提示填写。字段长度采用人格接口契约；描述提示为“写下人物的身份、性格，以及你希望演绎时使用的资料”。用户可自由组织全文，支持粘贴、撤销、文本选择和输入法。
2. 描述中的 Enter 换行；Ctrl+Enter 或 Cmd+Enter 提交，按钮提供相同操作。字段标签明确区分账号昵称与人格姓名。
3. **C04、C05**：提交前校验字段，聚焦首个错误。保存中固定本次输入并显示“正在保存人格…”，避免重复创建。成功后携带已创建标识回来源；列表或开始页按自身规则重读与定位。
4. 明确失败保留姓名和完整描述并显示可修正原因；结果待确认时按 S02 处理，提供“核对保存结果”和“返回来源”。已创建但返回页面读取失败时，继续读取同一人格。
5. **C01**：空表单直接返回；存在未保存内容时提供“继续填写”“保留草稿并离开”“放弃草稿并离开”。浏览器刷新使用可用的离开提示并按第 7 节恢复。取消操作及成功返回均保持原开始任务中的角色与开场上下文。
6. 按钮提供悬停、按下和焦点反馈，字段错误关联输入；保存进度与结果使用礼貌播报。

## 5. 页面状态流转

| 状态             | 呈现与后续                     |
| ---------------- | ------------------------------ |
| 可填写／草稿恢复 | 空字段或恢复内容，显示恢复提示 |
| 校验失败         | 原输入及字段错误               |
| 保存中           | 固定字段、提交进度、返回入口   |
| 明确失败         | 原因与可修正字段               |
| 结果待确认       | 保留输入与核对入口             |
| 已创建           | 返回来源并传递人格标识         |
| 身份失效         | S01 恢复登录后核对当前账号     |
| 离线             | 保留草稿，连接恢复后核对请求   |

## 6. 动效说明

1. 字段、保存及草稿反馈使用 `--motion-duration-feedback`、`--motion-easing-standard`；返回定位由来源页负责。
2. 减少动态效果时直接更新，描述长度变化保持当前光标与阅读位置。

## 7. 数据策略

1. 草稿以当前标签页、账号及来源任务区分，保存姓名、描述和来源上下文。离开选择保留时或刷新恢复时回填；保存成功或放弃后移除该草稿，退出账号按 F01 清理。
2. 身份恢复后先确认当前账号；草稿只恢复到所属账号。创建请求结果按 S02 核对，响应丢失的关联证据按功能依据接入验收。
3. 从开始页进入时，创建完成后的当前选择由 P13 第 4 节 C04 处理。默认人格的变化遵循需求规格；表单反馈以已确认创建结果为准。

## 8. 适配说明

1. 桌面与外接键盘支持字段遍历及提交快捷键，中文输入法组词期间保留原生行为。手机姓名输入后可移动至描述。
2. 长描述可完整编辑和复制；字号放大、横屏及窄屏时页面可纵向滚动。触控范围与间距采用 `--size-target-min`、`--space-control-gap`。
3. 恢复草稿提示与字段错误可以读屏读取，焦点不会被自动保存草稿移动。具体视觉验收见目录说明第 1 节。

## 9. 交互走查

| 验收项                     | 依据       |
| -------------------------- | ---------- |
| 字段、姓名与完整描述       | 第 1、4 节 |
| 校验、输入法与长文编辑     | 第 4、8 节 |
| 保存失败、待确认与唯一目标 | 第 4、5 节 |
| 取消、草稿与刷新恢复       | 第 4、7 节 |
| 两类来源与成功返回         | 第 1、7 节 |
| 账号归属、软键盘和读屏     | 第 7、8 节 |

## 10. 特定场景微交互说明

1. **恢复草稿**：行为采用第 7 节。恢复提示位于表单标题下，字段回填后保持编辑起点可见；用户开始输入后提示仍可阅读，避免遮挡正文。
2. **保存反馈**采用第 4 节 C04、C05，反馈固定在表单末尾。使用第 6 节 token，声音与振动关闭。
