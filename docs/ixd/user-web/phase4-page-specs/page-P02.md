# P02：角色广场（手机 Web）

## 1. 页面概述

1. 本页属于角色选择 L1，面向访客及登录用户；详情目标为 P04，开始目标为 P14。任务、字段和共用行为采用 [P01](page-P01.md)。
2. 主导航采用阶段 2 的手机底部导航；账号入口按登录身份进入 P05 或 P08。

## 2. 页面布局

1. 手机结构如下。

```text
角色广场 │ 账号入口
搜索输入 · 搜索
分类选项（换行）· 重置
已应用条件与结果范围
角色卡单列列表
加载更多／读取反馈
底部主导航
```

2. 正文纵向滚动，底部导航避开安全区域并留出内容空间。搜索与分类随正文滚动；浏览器后退返回时恢复列表锚点。横屏仍保持清晰的卡片阅读顺序。

## 3. 组件清单

| 编号 | 组件           | 手机位置       | 操作                 |
| ---- | -------------- | -------------- | -------------------- |
| C01  | 标题与账号入口 | 顶部           | 登录或打开 P08       |
| C02  | 搜索           | 正文首部       | 输入并应用关键词     |
| C03  | 分类与重置     | 搜索下方       | 选择分类或恢复全部   |
| C04  | 角色列表与范围 | 正文           | 打开 P04 或 P14      |
| C05  | 加载反馈       | 列表尾部或空态 | 加载更多、重试、重置 |
| C06  | 主导航         | 底部           | 切换四个 L1 模块     |

## 4. 交互行为详述

1. 搜索、分类和角色操作采用 P01 第 4 节。手机搜索键与页面搜索按钮执行同一动作；提交后收起软键盘，焦点语义仍归搜索控件，结果提示可被辅助技术读取。
2. 分类标签换行展示，点击标签完成选择；选中状态同时通过文字语义表达。卡片“查看详情”和“开始演绎”各自可点击，长按文本保留浏览器选择行为。
3. 主导航按当前模块标记角色广场；再次点击当前项保留筛选和位置。返回列表、加载更多及条件改变采用 P01 第 7 节。

## 5. 页面状态流转

1. 查询状态采用 P01 第 5 节；手机特定状态如下。

| 状态             | 呈现与操作                           |
| ---------------- | ------------------------------------ |
| 输入中           | 搜索框及提交按钮位于键盘上方可见区域 |
| 查询更新         | 结果标题下显示更新反馈               |
| 无匹配或集合为空 | 结果区显示对应操作                   |
| 追加失败         | 最后一张卡后保留重试入口             |
| 后台恢复         | 保留条件与位置，重新读取当前查询     |

## 6. 动效说明

1. 查询与卡片反馈采用 P01 第 6 节。

## 7. 数据策略

1. 搜索、分页、缓存和图片加载引用 P01 第 7 节。移动网络切换后，保留已取得列表并重试当前条件。
2. 从后台恢复或页面重建时，恢复同一查询与已读角色；资源重读失败时保留可读部分和重试入口。打开个人资源前按 S01 校验当前身份。

## 8. 适配说明

1. 点击区域与相邻间距使用 `--size-target-min`、`--space-control-gap`。长名称和标签允许换行；图片失败的文本替代采用 P01 第 8 节。
2. 软键盘展开跟随浏览器视口，底部导航在键盘遮挡时让位于输入区域。搜索聚焦时保持输入与错误提示可见，文字放大后底部导航仍可读取。屏幕阅读顺序与视觉顺序一致；外接键盘使用 P01 的搜索、选择和焦点规则。
3. 安全区域、横屏及浏览器工具栏变化由可见视口布局处理，具体视觉验收采用目录说明第 1 节。

## 9. 交互走查

1. 手机任务按下表验收，数据结果与 P01 采用相同依据。

| 分类、重置与角色入口           | 第 3、4 节 |
| 空态、错误及分页               | 第 5、7 节 |
| 后退、后台与网络恢复           | 第 4、7 节 |
| 点击范围、长文、键盘与屏幕阅读 | 第 8 节    |

## 10. 特定场景微交互说明

1. **提交手机搜索**：行为采用第 4 节第 1 项。键盘收起后，更新提示保持在结果标题下；查询反馈采用 P01 第 10 节。
2. 浏览器视口变化时保留搜索控件位置，声音与振动关闭；减少动态效果时直接显示结果状态。
