# P03：角色详情（桌面 Web）

## 1. 页面概述

1. 本页属于角色选择 L2，由 P01 打开；用户了解角色后进入 P13。任务采用[阶段 3 F03](../phase3-userflows.md)。
2. 角色资料来源采用[功能依据](../feature-basis.md)。本页展示角色发布内容中的介绍；开场选择位于 P13。

## 2. 页面布局

```text
站点侧栏 │ 顶栏
         │ 返回角色广场
         │ 封面与作者 │ 角色名称、摘要、标签
         │            │ 故事介绍全文
         │            │ 可用状态 · 开始演绎
```

1. 主区域纵向滚动，内容列容纳长篇介绍。开始入口与可用状态相邻；正文较长时可在内容列底部粘附该入口，并为最后一段预留空间。
2. 图片与文本分别加载，页面完整展示文字内容。可用宽度不足时封面移到正文上方。

## 3. 组件清单

| 编号 | 组件           | 区域／类型           | 操作                       |
| ---- | -------------- | -------------------- | -------------------------- |
| C01  | 返回广场       | 页首／导航           | 恢复 P01 的筛选和位置      |
| C02  | 角色资料       | 主区域／图文         | 阅读名称、作者、标签及故事 |
| C03  | 开始演绎       | 正文末尾／按钮       | 进入 P13                   |
| C04  | 可用状态与恢复 | 操作附近／状态与按钮 | 重试读取或返回广场         |

## 4. 交互行为详述

1. **C01**：返回 P01 并按该页第 7 节恢复列表；直接访问详情时返回广场默认列表。浏览器前进后退使用同一角色标识。
2. **C02**：角色名称和故事以可选择文本展示；缺少可选字段时省略该字段。故事正文内有角色提供的链接时使用常规浏览器链接，链接文字说明目标，返回后恢复本页阅读位置。
3. **C03**：资源可开始时进入 P13；访客按 S01 登录并恢复该目标。按钮在资源读取中或已知不可开始时显示相应原因。打开选择页后继续由 P13 核对资源。
4. **C04**：网络失败保留已取得资料并提供重新读取；角色不存在或无权访问时进入 P22。正文或图片单项失败只影响对应区域，开始操作取决于必要发布资源的有效状态。
5. 按钮、链接支持悬停、按下、焦点和键盘激活；读取完成保留用户焦点，页面标题作为导航到达点。

## 5. 页面状态流转

| 状态       | 条件               | 呈现与后续                       |
| ---------- | ------------------ | -------------------------------- |
| 加载       | 初次读取           | 标题与正文读取反馈，开始暂不可用 |
| 可开始     | 发布资源有效       | 完整资料及开始入口               |
| 暂不可开始 | 发布状态不满足     | 资料可读，原因与重新读取         |
| 部分失败   | 图片或可选资料失败 | 文本替代或局部重试               |
| 请求失败   | 必要资料未取得     | 重试或返回                       |
| 访问失效   | 不存在或无权访问   | S01 转 P22                       |

## 6. 动效说明

1. 加载反馈与按钮状态使用 `--motion-duration-feedback`、`--motion-easing-standard`；页面进入采用 `--motion-duration-page`。
2. 封面预留布局空间，正文直接呈现；减少动态效果时直接切换页面及状态。

## 7. 数据策略

1. 按角色与可访问发布标识读取，页面只接收匹配当前目标的响应。开始前的发布状态以最近成功读取和创建时校验为依据。
2. 返回详情时可先显示已读资料，再重新核对可用性。页面再次可见或用户重试时重读；变化后的内容保留原阅读锚点，失效目标按 S01 处理。
3. 正文为单个角色资源，使用文档滚动阅读；大型图片按可见范围加载。离线时已取得资料可读，开始操作等待连接与资源核对。

## 8. 适配说明

1. 长名称、标签和介绍自然换行；图片失败保留角色文本，宽表格在自身区域滚动。手机布局见 [P04](page-P04.md)。
2. 封面替代文本、标题层级和链接名称表达内容用途。键盘按返回、正文链接、开始及恢复入口遍历；触控范围采用 `--size-target-min`。
3. 缩放后正文与粘附操作互不遮挡，视觉与浏览器验收采用目录说明第 1 节。

## 9. 交互走查

| 验收项                   | 依据          |
| ------------------------ | ------------- |
| 返回与角色目标恢复       | 第 4、7 节    |
| 资料来源、长文及图片失败 | 第 4、7、8 节 |
| 开始资格与登录恢复       | 第 4 节 C03   |
| 部分失败、离线与访问失效 | 第 5、7 节    |
| 键盘、触控与缩放阅读     | 第 8 节       |

## 10. 特定场景微交互说明

1. **开始入口状态变化**：行为采用第 4 节 C03、C04。按钮旁保留同一反馈区域，读取期间及失败后在该区域显示原因；按钮的焦点位置保持稳定。
2. 使用第 6 节 token，声音与振动关闭。重新读取后的资格变化按第 5 节处理。
