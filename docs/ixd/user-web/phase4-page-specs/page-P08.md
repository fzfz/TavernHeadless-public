# P08：用户中心（手机 Web）

## 1. 页面概述

1. 本页属于用户中心 L1，面向当前账号。共用规则采用 [P07](page-P07.md)；人格、历史目标分别为 P10、P16，退出后回 P02。

## 2. 页面布局

```text
用户中心
账号资料 · 编辑昵称
演绎人格入口 · 数量
历史演绎入口 · 数量
退出登录
底部主导航
```

1. 手机使用单列，资料、资源、退出分别成组；昵称编辑在原位置展开。正文为底部导航和安全区域预留空间。
2. 键盘展开时输入与保存区域进入可见视口，底部主导航让位于输入区域。

## 3. 组件清单

| 编号 | 组件         | 位置     | 操作                 |
| ---- | ------------ | -------- | -------------------- |
| C01  | 账号资料     | 正文顶部 | 阅读账号资料         |
| C02  | 昵称编辑     | 资料区   | 输入、保存、取消     |
| C03  | 个人资源入口 | 正文中部 | 打开 P10、P16        |
| C04  | 退出及反馈   | 正文底部 | 退出、读取或核对结果 |
| C05  | 主导航       | 底部     | 切换模块             |

## 4. 交互行为详述

1. 账号、昵称、统计、退出及草稿行为采用 P07 第 4 节。手机输入的完成键与保存按钮执行同一校验提交，输入法组词期间保留原生行为。
2. 保存成功收起键盘，昵称及结果提示在原位置显示；失败保持编辑态，将关联错误带入视口。点击资源入口与主导航的离开处理采用 P07 的草稿规则。
3. 每个资源入口整行可点击，数量是该入口的辅助信息；退出拥有独立按钮。操作采用常驻控件，长按文字保留选择行为。

## 5. 页面状态流转

| 状态           | 手机呈现与后续               |
| -------------- | ---------------------------- |
| 资料或统计加载 | 各区域分别反馈               |
| 编辑中／失败   | 软键盘上方保持输入与错误可达 |
| 保存中／待确认 | 资料区显示进度或核对         |
| 部分失败       | 个人资源入口保持可用         |
| 后台恢复       | 重读当前账号，按规则恢复草稿 |
| 已退出         | 返回访客 P02                 |

## 6. 动效说明

1. 编辑与保存采用 P07 第 6 节 token；键盘视口变化跟随浏览器。减少动态效果时直接呈现。

## 7. 数据策略

1. 数据范围、计数、草稿及离线处理采用 P07 第 7 节。手机后台恢复时先核对身份再读取个人数据。
2. 浏览器回收页面后，恢复草稿须匹配当前账号；退出后的返回导航按 S01 重新校验身份。

## 8. 适配说明

1. 点击范围与间距采用 `--size-target-min`、`--space-control-gap`；长昵称和账号标识换行，横屏和文字放大后表单仍可纵向滚动。
2. 屏幕阅读顺序与第 2 节一致，外接键盘按 P07 的顺序遍历。软键盘展开时保持输入及关联错误可见。
3. 数量的读取状态与零值沿用 P07；视觉实测采用目录说明第 1 节。

## 9. 交互走查

| 验收项                   | 依据         |
| ------------------------ | ------------ |
| 手机昵称输入、保存与取消 | 第 4 节      |
| 个人资源与退出目标       | 第 1、3 节   |
| 局部失败、计数与待确认   | 第 5 节、P07 |
| 后台、账号与草稿恢复     | 第 7 节      |
| 触控、键盘、长文本与读屏 | 第 8 节      |

## 10. 特定场景微交互说明

1. **昵称保存后收起键盘**：行为采用第 4 节第 2 项。视口恢复后保持昵称区域在原阅读位置，保存反馈采用 P07 第 10 节。
2. 声音与振动关闭，减少动态效果时直接呈现。
