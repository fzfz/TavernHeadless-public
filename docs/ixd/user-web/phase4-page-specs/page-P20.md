# P20：本次演绎人设（桌面与手机 Web）

## 1. 页面概述

1. 本弹层从 P17／P18 或 P19 打开，沿用宿主页层级。用户阅读当前会话保存的人格姓名及完整描述，关闭后回到发起位置。
2. 资料含义与生命周期采用[需求规格第 3 节](../user-web-requirements.md)，访问与恢复采用阶段 3 的 S01。

## 2. 页面布局

```text
本次演绎人设 · 关闭
人格姓名
人设说明（见第 4 节 C02）
完整描述
读取反馈／重试
```

1. 桌面使用宿主对话框，手机使用可扩展至可用视口的底部对话框。长描述在内容区域纵向滚动，标题及关闭入口保持可达。
2. 背景会话的阅读位置与输入保留；从 P19 打开时使用该页的覆盖层切换方式。

## 3. 组件清单

| 编号 | 组件           | 类型       | 操作             |
| ---- | -------------- | ---------- | ---------------- |
| C01  | 关闭           | 按钮       | 返回发起位置     |
| C02  | 姓名与完整描述 | 只读文本   | 阅读、选择和复制 |
| C03  | 读取反馈       | 状态与按钮 | 重试读取快照     |

## 4. 交互行为详述

1. **C02**：显示会话保存的姓名及完整描述。正文保持段落与可选择文本，长描述可持续滚动阅读。
2. **C01**：关闭、Esc、点击外部或手机返回均回到发起位置；来自 P19 时回到设置，来自会话时回到会话。焦点回到原触发入口。
3. **C03**：读取失败显示“人设资料读取失败”及重试；已取得部分字段时保留可读字段并标明其余内容的读取状态。快照缺少姓名或描述时，分别显示“此会话未保存人格姓名”或“此会话未保存人设描述”。
4. 按钮提供悬停、按下和焦点反馈，读取结果使用礼貌播报。打开后的焦点位于标题或关闭入口，正文可以通过读屏连续阅读。

## 5. 页面状态流转

| 状态     | 呈现与后续             |
| -------- | ---------------------- |
| 加载     | 标题、关闭与读取反馈   |
| 已读取   | 姓名及完整描述         |
| 字段缺失 | 已有资料与明确缺失提示 |
| 部分失败 | 可读字段与局部重试     |
| 读取失败 | 重试或关闭             |
| 会话失效 | 按 S01 恢复访问        |

## 6. 动效说明

1. 弹层使用 `--motion-duration-overlay`、`--motion-easing-standard`，读取反馈使用 `--motion-duration-feedback`。减少动态效果时直接呈现。
2. 长文重读时保持阅读锚点；正文加载完成避免自动滚动到末尾。

## 7. 数据策略

1. 只按当前账号和会话读取人格快照，使用已确认的会话数据或读取结果。源人格的编辑和删除按需求规格处理，快照字段缺失时按 C03 展示。
2. 打开弹层或会话恢复后核对当前会话数据；相同会话的阅读位置保留到弹层关闭，切换会话使用该会话自己的内容与位置。
3. 离线可读已取得的快照，失败部分在连接恢复后重试。

## 8. 适配说明

1. 姓名和描述自然换行，长段落与文本选择在窄屏和放大下保持可用；手机关闭按钮避开安全区域，点击范围采用 `--size-target-min`。
2. 弹层使用对话框及标题语义，背景退出焦点顺序。外接键盘可关闭和滚动，长按正文保留复制；打开时收起会话键盘并保持原输入。
3. 读屏按标题、姓名、描述、反馈顺序读取，具体视觉验收见目录说明第 1 节。

## 9. 交互走查

| 验收项                   | 依据          |
| ------------------------ | ------------- |
| 人格快照来源与完整内容   | 第 1、4、7 节 |
| 长文、字段缺失和读取失败 | 第 4—7 节     |
| 从设置或会话返回         | 第 4 节 C01   |
| 账号、会话切换及离线     | 第 7 节       |
| 焦点、触控、复制与读屏   | 第 8 节       |

## 10. 特定场景微交互说明

1. **读取完成**：行为采用第 4 节 C02、C03。加载提示原位置转换为正文起点，标题和关闭入口保持位置，用户已在阅读的字段保持锚点。
2. 使用第 6 节 token，声音与振动关闭；关闭后的焦点行为引用 C01。
