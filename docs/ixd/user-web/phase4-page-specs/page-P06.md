# P06：注册（桌面与手机 Web）

## 1. 页面概述

1. 本页从 P05 进入，按[阶段 3 F01](../phase3-userflows.md)创建账号，成功后返回 P05 登录。原目标在账号流程中持续保留。
2. 注册服务及模拟原型标识采用 [P05 第 1 节](page-P05.md)与功能依据。

## 2. 页面布局

```text
返回登录
创建账号
昵称
邮箱
密码 · 显示／隐藏
确认密码 · 显示／隐藏
字段与提交反馈
创建账号
已有账号，去登录
```

1. 双端使用单列表单；桌面与手机的页面外框采用 P05 第 2 节。说明紧邻对应字段，提交位于字段之后，长错误随文档滚动。

## 3. 组件清单

| 编号 | 组件           | 类型           | 操作             |
| ---- | -------------- | -------------- | ---------------- |
| C01  | 返回登录       | 导航           | 回 P05           |
| C02  | 昵称           | 单行输入       | 输入账号显示名称 |
| C03  | 邮箱           | 单行输入       | 输入注册邮箱     |
| C04  | 密码与确认密码 | 密码输入及显隐 | 设置并确认密码   |
| C05  | 创建账号       | 提交           | 提交注册         |
| C06  | 注册结果       | 状态及按钮     | 核对结果或去登录 |

## 4. 交互行为详述

1. **C02—C04**：昵称、邮箱、密码和确认密码必填。昵称的字段说明为“用于显示你的账号名称”；人格姓名由 P11 设置。邮箱格式、字段长度及密码要求采用接入后的身份服务契约，并在输入前展示实际要求。
2. 密码与确认密码使用 `new-password` 自动填充，昵称使用 `nickname`，邮箱使用 `username`。显隐、粘贴、输入法及字段错误反馈采用 P05 第 4 节；确认密码与密码不一致时在确认字段提示重新核对。
3. **C05**：本地校验通过后固定本次输入并显示“正在创建账号…”，锁定重复提交。明确失败保留可修正输入，并将服务端可操作原因显示在对应字段或表单反馈处。
4. **C06**：明确已创建后回 P05，带回邮箱并显示“账号已创建，请登录”。结果待确认时按 S02 核对，提供“核对注册结果”和“去登录”；登录成功作为账号可用的证据。注册与登录的接口入口见[功能依据](../feature-basis.md#2-功能与数据来源)。
5. **C01**：返回 P05 时保留邮箱及原目标，密码清理规则采用 P05 第 7 节。账号创建已发出时离开页面保留操作核对信息，回到注册页先核对已有结果。

## 5. 页面状态流转

| 状态           | 呈现与后续                   |
| -------------- | ---------------------------- |
| 可填写         | 字段、规则说明与提交         |
| 校验失败       | 聚焦首个错误，保留其他输入   |
| 创建中         | 显示进度，返回登录仍可用     |
| 明确拒绝       | 原因与可修正字段             |
| 创建结果待确认 | 核对或去登录                 |
| 已创建         | 返回 P05 并提示登录          |
| 离线或核对失败 | 保留本页输入，重试读取或返回 |

## 6. 动效说明

1. 字段与提交反馈采用 P05 第 6 节 token。成功提示随 P05 的到达状态呈现。
2. 减少动态效果时直接呈现，校验提示保持字段位置稳定。

## 7. 数据策略

1. 表单内容按当前标签页的账号流程隔离；密码的保留范围采用 P05 第 7 节。昵称和邮箱草稿可在本标签页注册往返时恢复。
2. 注册写入及结果核对使用 S02；再次进入先检查已有操作结果。明确未创建后才能再次提交；服务返回的字段规则作为验证依据。
3. 离线时保留当前内存输入，恢复后先核对已发出的请求。新账号的个人资源初始化行为采用需求规格第 3 节。

## 8. 适配说明

1. 手机按昵称、邮箱及密码类型提供输入方式；键盘展开时提交和错误可滚动到达。外接键盘按字段顺序遍历，组词期间保留输入法行为。
2. 大字、长昵称及错误换行保持单列；显隐按钮与字段独立聚焦。触控、读屏及视觉验收采用 P05 第 8 节。

## 9. 交互走查

| 验收项                       | 依据        |
| ---------------------------- | ----------- |
| 账号昵称与人格姓名区分       | 第 4 节 C02 |
| 校验、密码确认与填充         | 第 4 节     |
| 已创建、未创建及待确认       | 第 4、5 节  |
| 返回登录、草稿及密码生命周期 | 第 5、7 节  |
| 软键盘、读屏与字段错误       | 第 8 节     |

## 10. 特定场景微交互说明

1. **密码确认错误**：行为采用第 4 节第 2 项。错误提示紧邻确认字段，校验结果更新时只替换说明及字段状态。
2. 使用第 6 节 token，声音与振动关闭。修正后按相同校验规则更新反馈。
