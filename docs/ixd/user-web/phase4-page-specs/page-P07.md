# P07：用户中心（桌面 Web）

## 1. 页面概述

1. 本页属于用户中心 L1，面向当前登录账号。任务采用[阶段 3 F01](../phase3-userflows.md)，访问采用 S01，昵称保存采用 S02。
2. 可展示字段、统计与权限接入情况见[功能依据第 2 节](../feature-basis.md)。人格入口进入 P09，历史入口进入 P15，退出后回访客 P01。

## 2. 页面布局

```text
站点侧栏 │ 用户中心顶栏
         │ 账号资料：昵称 · 编辑；账号标识
         │ 演绎人格入口 · 人格数量
         │ 历史演绎入口 · 会话数量
         │ 退出登录
```

1. 资料、资源入口及退出操作分组，主内容纵向滚动。昵称编辑直接替换昵称展示区域，保留其他入口的位置。

## 3. 组件清单

| 编号 | 组件           | 类型       | 操作                       |
| ---- | -------------- | ---------- | -------------------------- |
| C01  | 账号资料       | 只读摘要   | 读取当前昵称及可用账号标识 |
| C02  | 编辑昵称       | 行内表单   | 编辑、保存、取消           |
| C03  | 人格入口       | 链接及数量 | 进入 P09                   |
| C04  | 历史入口       | 链接及数量 | 进入 P15                   |
| C05  | 退出登录       | 按钮       | 结束当前登录               |
| C06  | 读取与保存反馈 | 状态与按钮 | 重试、核对结果             |

## 4. 交互行为详述

1. **C01**：展示身份服务可确认的账号标识；原型邮箱按功能依据标明模拟数据。昵称为账号资料，演绎中扮演的姓名从人格资源读取。
2. **C02**：点击编辑后填入已保存昵称，显示保存与取消。保存按账号接口的必填与长度规则校验，错误关联字段；Enter 在组词完成后保存，Esc 取消并恢复已保存值。保存中固定输入并锁定重复提交；失败保留草稿，待确认时提供核对入口。
3. 用户点击取消即放弃该次昵称输入；站内离开编辑状态时提供“继续编辑”和“离开并保留草稿”。返回后重新读取账号资料，再让用户确认草稿与当前昵称。
4. **C03、C04**：入口在统计读取失败时仍可进入所属列表；数量只有完整集合计数可确认时显示，读取中显示加载提示，失败显示“数量暂不可用”。
5. **C05**：点击后本地结束登录并清理个人页面数据，回到访客角色广场；远端凭据处理按 F01。远端退出结果不明时说明“此浏览器已退出登录，服务端退出结果仍待确认”，提供“核对退出结果”入口。
6. **C06**：账号资料读取失败在资料区重试；统计单项失败局部反馈。身份失效按 S01 处理。按钮具有悬停、按下及焦点反馈，保存与退出结果采用状态播报。

## 5. 页面状态流转

| 状态           | 呈现与后续                   |
| -------------- | ---------------------------- |
| 资料加载       | 资料与统计各自反馈，导航可用 |
| 资料就绪       | 展示当前账号及个人资源入口   |
| 编辑或校验失败 | 输入与关联错误，保存及取消   |
| 保存中／待确认 | 进度或核对入口，保留草稿     |
| 部分读取失败   | 成功区域可用，失败区域重试   |
| 身份失效       | S01 恢复登录                 |
| 已退出         | 访客广场及必要的退出状态提示 |

## 6. 动效说明

1. 行内编辑及状态反馈使用 `--motion-duration-feedback`、`--motion-easing-standard`。保存成功后恢复展示区域并保持其位置。
2. 减少动态效果时直接切换；退出后的页面切换使用 `--motion-duration-page`。

## 7. 数据策略

1. 页面分别读取当前账号的资料与统计。完整数量的来源与账号字段映射按功能依据接入；页面只使用当前身份对应响应。
2. 昵称草稿按当前标签页与账号保存；刷新或返回后先重读，再显示恢复提示。已保存值发生变化时同时呈现当前值与草稿，用户重新确认后提交。
3. 页面恢复可见时刷新账号与数量。离线可读已取得资料，保存等待连接；退出始终可以结束当前设备的登录状态。账号清理采用 F01 的退出规则。

## 8. 适配说明

1. 页面缩窄时资源入口纵向排列；长昵称与账号标识允许换行。用户按 Tab 键时，焦点依次经过资料编辑、个人资源、反馈操作和退出按钮。
2. 昵称标签与错误关联，保存成功焦点回编辑按钮。触控范围采用 `--size-target-min`；手机布局见 [P08](page-P08.md)。
3. 数量读取失败与零值使用不同文本；对比度、焦点及主题验收见目录说明第 1 节。

## 10. 特定场景微交互说明

1. **昵称保存**：行为采用第 4 节 C02。进度与错误显示在昵称区，成功提示与已保存昵称共同呈现；布局保留原编辑按钮位置。
2. 动效采用第 6 节；声音与振动关闭。
