# P04：角色详情（手机 Web）

## 1. 页面概述

1. 本页属于角色选择 L2，从 P02 进入，开始演绎进入 P14。资料、任务和共用行为采用 [P03](page-P03.md)。

## 2. 页面布局

```text
返回广场 │ 角色详情
角色封面
角色名称 · 作者 · 标签
摘要与故事介绍全文
可用状态
底部：开始演绎
```

1. 页面采用单列纵向滚动，子页导航使用阶段 2 的手机返回结构。底部开始区避开安全区域并预留正文空间；横屏或文字放大导致正文空间不足时移入文档流。
2. 故事介绍完整展开，用户通过浏览器滚动阅读。封面高度由视觉阶段确定，角色名称和介绍保持可快速到达。

## 3. 组件清单

| 编号 | 组件       | 位置     | 操作       |
| ---- | ---------- | -------- | ---------- |
| C01  | 返回广场   | 顶栏     | 回到 P02   |
| C02  | 角色资料   | 正文     | 阅读图文   |
| C03  | 开始演绎   | 底部     | 进入 P14   |
| C04  | 状态与恢复 | 对应区域 | 重试或返回 |

## 4. 交互行为详述

1. 资料阅读、可用资格与失败处理采用 P03 第 4 节。开始操作需登录时保留 P14 及角色目标，登录完成后继续。
2. 点击开始有即时按下反馈；等待或暂不可开始的原因显示在开始按钮附近。长按正文保留选择复制，图片失败保留可读替代信息。
3. 顶栏返回与浏览器后退均恢复 P02 原条件和已读角色。正文链接的返回按 P03 的阅读恢复规则处理。

## 5. 页面状态流转

| 状态           | 手机呈现与后续                 |
| -------------- | ------------------------------ |
| 加载           | 正文读取反馈，底部显示等待原因 |
| 可开始         | 资料及底部入口可用             |
| 暂不可开始     | 说明原因，保留阅读与重新读取   |
| 局部失败或离线 | 保留成功部分及恢复入口         |
| 访问失效       | 按 S01 进入 P22                |
| 后台恢复       | 保留阅读位置，核对资源状态     |

## 6. 动效说明

1. 页面与按钮反馈采用 P03 第 6 节 token。

## 7. 数据策略

1. 资源归属、缓存、图片及可用性刷新采用 P03 第 7 节。手机从后台恢复时保留正文锚点，再读取当前角色可用状态。
2. 网络恢复后重新核对必要发布资源，操作结果匹配当前角色后更新底部入口。

## 8. 适配说明

1. 窄屏、横屏和大字场景下保持全文换行及操作可达；图片按容器适配，长表格在内容内部滚动。
2. 浏览器工具栏变化时按可见视口布置底部操作。点击范围与间距采用 `--size-target-min`、`--space-control-gap`。屏幕阅读按顶栏、角色资料、开始与恢复入口顺序；外接键盘沿用 P03 的访问方式。
3. 读屏焦点与当前阅读位置在底部操作变化时保持稳定；具体视觉验收见目录说明第 1 节。

## 9. 交互走查

| 验收项                   | 依据       |
| ------------------------ | ---------- |
| 手机返回与登录后目标     | 第 4 节    |
| 长文阅读、底部操作与大字 | 第 2、8 节 |
| 可用状态与图片失败       | 第 4、5 节 |
| 后台、缓存和网络恢复     | 第 7 节    |
| 触控、键盘与屏幕阅读     | 第 8 节    |

## 10. 特定场景微交互说明

1. **底部开始入口反馈**采用 P03 第 10 节，位置采用本页第 2 节。文字放大使反馈区域增高时，操作区随文档流调整，保持正文可阅读。
2. 状态反馈采用 P03 第 6 节，声音与振动关闭。
