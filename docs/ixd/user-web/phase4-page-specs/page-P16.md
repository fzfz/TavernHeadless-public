# P16：历史演绎（手机 Web）

## 1. 页面概述

1. 本页属于历史管理 L1，入口为主导航、P08 和 P18。任务与数据规则采用 [P15](page-P15.md)，继续进入 P18，开始新演绎进入 P02。

## 2. 页面布局

```text
历史演绎 · 开始新演绎
搜索输入 · 搜索 · 清除
管理记录
单列会话条目：标题、角色、人格、更新时间
继续 · 更多
管理模式：选择框 · 已选数量 · 删除所选 · 完成
加载更多
底部主导航
```

1. 普通阅读优先显示继续入口；“管理记录”展开选择框及批量操作区。管理操作位于列表上方，底部主导航保持其原位置。
2. 标题编辑在条目内展开，键盘出现时输入与保存区域进入可见视口。正文为底部导航和安全区域预留空间。

## 3. 组件清单

| 编号 | 组件         | 位置     | 操作               |
| ---- | ------------ | -------- | ------------------ |
| C01  | 搜索及开始   | 页首     | 应用条件或去 P02   |
| C02  | 会话与继续   | 正文     | 打开 P18           |
| C03  | 管理记录     | 列表上方 | 展开选择或完成管理 |
| C04  | 选择与删除   | 管理区域 | 勾选并进入 P21     |
| C05  | 更多与重命名 | 条目内   | 编辑标题或删除     |
| C06  | 加载与反馈   | 对应区域 | 追加、重试或核对   |

## 4. 交互行为详述

1. 搜索、继续、选择范围及管理结果采用 P15 第 4 节，手机搜索键与页面按钮执行相同查询。搜索提交后收起键盘，结果反馈留在列表标题附近。
2. 点击“管理记录”显示每项选择框和“选择已加载记录”，该总选择动作采用 P15 第 4 节 C04；点击“完成”退出管理并清空未提交选择。已经提交的删除结果继续按 P21 核对。
3. 管理模式下点击选择区域只改变勾选；“继续”保留独立入口。普通模式始终显示“更多”按钮，长按标题保留浏览器文本选择。
4. 标题保存与取消采用 P15 的规则，保存成功收起键盘并保持该条目可见。菜单点击外部或手机返回关闭，焦点回到对应会话的更多按钮。

## 5. 页面状态流转

| 状态             | 手机呈现与后续                 |
| ---------------- | ------------------------------ |
| 普通列表         | 继续与更多入口                 |
| 管理模式         | 选择框、数量及删除所选         |
| 标题编辑         | 键盘、输入及关联反馈           |
| 空历史／无匹配   | 对应开始或清除入口             |
| 局部失败／待确认 | 列表保留成功部分及核对入口     |
| 后台恢复         | 重新读取当前查询和已有操作结果 |

## 6. 动效说明

1. 管理区域展开、菜单及条目反馈采用 P15 第 6 节 token；选择框出现时为条目保留稳定的文本对齐位置。
2. 减少动态效果时直接呈现。

## 7. 数据策略

1. 查询、分页、草稿及账号隔离采用 P15 第 7 节。管理模式与选择保存在本标签页的当前查询范围内，浏览器页面重建后先读取目标再恢复有效选择。
2. 手机从后台或网络切换恢复后，优先核对已发出的写入；成功读取的数据保留供阅读，继续目标始终为原会话。

## 8. 适配说明

1. 点击范围与间距采用 `--size-target-min`、`--space-control-gap`。勾选、继续与更多各自拥有独立区域，长标题和姓名可换行。
2. 外接键盘与读屏采用 P15 第 8 节；“管理记录”表达展开状态。软键盘展开时保持标题字段和错误可见，横屏和大字场景通过文档滚动访问全部操作。
3. 底部导航与浏览器工具栏变化按可见视口布局，视觉验收见目录说明第 1 节。

## 10. 特定场景微交互说明

1. **管理模式切换**：行为采用第 4 节第 2 项。选择框和已选数量同时更新，条目正文保留阅读锚点；退出时焦点回“管理记录”。
2. 动效使用第 6 节 token，声音与振动关闭。标题编辑反馈采用 P15 第 10 节。
