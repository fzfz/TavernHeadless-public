# P15：历史演绎（桌面 Web）

## 1. 页面概述

1. 本页属于历史管理 L1，入口为主导航、P07 及 P17 返回。用户管理当前账号的会话，继续目标为 P17，开始新演绎入口进入 P01。
2. 任务采用[阶段 3 F05](../phase3-userflows.md)，访问和写入结果分别采用 S01、S02。历史字段与接口状态见[功能依据第 2 节](../feature-basis.md)。

## 2. 页面布局

```text
站点侧栏 │ 历史演绎 · 开始新演绎
         │ 搜索标题、角色或人格 · 搜索 · 清除
         │ 已加载范围 · 选择已加载记录 · 已选数量 · 删除所选
         │ 选择框 │ 会话标题、角色、人格、更新时间 │ 继续 · 更多
         │ 行内重命名与条目反馈
         │ 加载更多／读取反馈
```

1. 主区域纵向滚动，标题与继续为条目的主要信息；选择框和更多菜单各自拥有操作区域。更新时间按实际资源展示，并提供可读取的完整时间。
2. 批量操作区位于列表上方，有选中条目时显示数量与删除入口。重命名在目标标题处展开，其他条目保持位置。

## 3. 组件清单

| 编号 | 组件           | 类型           | 操作               |
| ---- | -------------- | -------------- | ------------------ |
| C01  | 开始新演绎     | 导航           | 进入 P01           |
| C02  | 历史搜索       | 输入与按钮     | 搜索或清除条件     |
| C03  | 会话条目与继续 | 列表与链接     | 打开指定会话       |
| C04  | 选择与批量操作 | 复选框及按钮   | 勾选条目、删除所选 |
| C05  | 更多与重命名   | 菜单及行内表单 | 修改标题或单项删除 |
| C06  | 加载和结果反馈 | 状态与按钮     | 追加、重读或核对   |

## 4. 交互行为详述

1. **C02**：输入关键词后点击搜索或组词结束后的 Enter 应用，搜索标题、角色或人格。切换已应用条件时清空选择，结果从首批开始；清除条件回到完整本人会话查询。输入草稿与当前结果条件分别呈现。
2. **C03**：点击继续或标题按 S01 打开原会话及其已保存分支；有待核对运行时由会话页恢复。返回本页后恢复原条件与该条目位置。
3. **C04**：“选择已加载记录”只选择当前已加载且可操作的条目，文案显示具体数量；加载更多后新增条目保持未选。用户可逐项取消，部分选中时总选择框表达混合状态。选择数量从当前所选标识集合计算；删除进入 P21。
4. 已知正在生成的会话保留继续入口，删除不可用并显示“演绎正在生成，请结束后再删除”。清单刷新发现目标已消失时更新选择并提示已移除的选择数量。
5. **C05**：更多菜单包含重命名与单项删除，菜单支持方向键、Enter 和 Esc。重命名预填当前标题，按会话标题契约校验；Enter 保存、Esc 取消，输入法组词期间按原生行为处理。保存中固定本次值，失败保留输入，待确认按 S02 核对。
6. 编辑标题时离开页面提供“继续编辑”和“离开并保留草稿”。同一条目的重命名与删除串行处理；单项和批量删除的确认、逐项结果及重试范围统一采用 [P21](page-P21.md)。
7. **C06**：无历史显示“还没有演绎记录”及开始入口；无搜索匹配显示修改或清除条件入口。首批失败在结果区重试，追加失败保留已有列表并在尾部重试。按钮具有悬停、按下及焦点反馈，操作结果在对应条目或批量区域播报。

## 5. 页面状态流转

| 状态             | 呈现与后续                 |
| ---------------- | -------------------------- |
| 加载／搜索更新   | 当前条件与读取反馈         |
| 有历史           | 会话条目与管理操作         |
| 历史为空         | 开始新演绎入口             |
| 搜索无匹配       | 修改或清除条件             |
| 已选择           | 选中数量与删除入口         |
| 重命名中／失败   | 行内输入及保存、取消或错误 |
| 部分删除／待确认 | 逐项结果，保留待处理目标   |
| 追加或刷新失败   | 已读内容可用，局部重试     |
| 身份失效         | S01 恢复访问               |

## 6. 动效说明

1. 选择、行内编辑、菜单和状态使用 `--motion-duration-feedback`、`--motion-easing-standard`。列表重新排序时保留当前阅读条目锚点。
2. 减少动态效果时直接更新；删除后的条目位置采用 P21 第 6 节。

## 7. 数据策略

1. 查询以账号和已应用搜索条件为范围，按实际更新时间倒序呈现；相同时间的顺序由后端稳定返回。分页与组合搜索的接入状态见功能依据，完整集合计数可确认时才显示总数，否则显示已加载数量。
2. 选择集合限于本次查询，刷新后与实际记录核对。批量目标在 P21 打开时固定，列表条件变化按 C02 处理。返回列表保留同一查询内仍有效的选择。
3. 标题草稿按标签页、账号与会话标识保存；刷新后重新读取目标，发现当前标题变化时展示保存值与草稿，用户重新确认。保存成功或取消后清理对应草稿，退出采用 F01。
4. 返回会话列表、页面再次可见及删除后刷新当前查询。移动网络或离线导致读取失败时保留成功部分，写入先按 S02 核对；账号变化后只更新对应账号的数据。

## 8. 适配说明

1. 窄屏或文字放大时，条目元信息和操作换行；长标题保留可读取全文的方式。手机布局见 [P16](page-P16.md)。
2. 键盘按搜索、批量操作、条目选择与操作、加载遍历；复选框名称包含会话标题。选中数量、错误与逐项结果可以被读屏获取；重命名结果保持条目焦点。
3. 触控范围采用 `--size-target-min`，选择框与继续入口各自独立。视觉及浏览器验收采用目录说明第 1 节。

| 选择范围、加载更多及批量结果 | 第 4 节 C04、P21 |

## 10. 特定场景微交互说明

1. **批量选择**：行为采用第 4 节 C04。复选标记与已选数量同步反馈，批量操作区保持稳定高度；用户取消选择时按同一规则更新。
2. **标题编辑**：行为采用第 4 节 C05。状态反馈附属于原条目，失败原因保留在输入附近。两个场景使用第 6 节 token，声音与振动关闭。
