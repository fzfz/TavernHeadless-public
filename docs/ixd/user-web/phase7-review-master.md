# 阶段 7：用户 Web 交互原型验收

## 1. 交付与运行

1. [桌面原型](phase7-prototype-desktop.html)与[手机原型](phase7-prototype-mobile.html)分别使用独立布局；两份 HTML 均包含运行所需的脚本、样式和角色 Runtime 示例资源。
2. 页面进度由 [progress.json](progress.json)记录。设备框上方提供主题与模拟状态切换，并标明当前页面的验收范围。
3. 原型使用[示例数据](prototype/data.mjs)。账号、角色查询和生成结果的接入边界见[需求规格第 5 节](user-web-requirements.md)与[功能依据](feature-basis.md)。
4. 在仓库根目录执行以下命令可生成双端 HTML 并启动预览；打包器使用仓库已有的 esbuild。

```sh
node docs/ixd/user-web/prototype/phase7/build.mjs
python3 -m http.server 4180 --bind 127.0.0.1 --directory docs/ixd/user-web
```

5. 预览地址分别为 `http://127.0.0.1:4180/phase7-prototype-desktop.html` 和 `http://127.0.0.1:4180/phase7-prototype-mobile.html`。两份文件也可直接在浏览器中打开。
