# 首批实施与验收记录

## 当前结论

独立图书馆预约样本使用 `nex-agi/nex-n2.5-pro:free` 执行了 15 次请求和 6 次离线重放。该样本通过身份及重启后记忆检查，但仍有前置条件衔接问题；原始角色发布、试聊和独立变量更新的真实联合验收继续保留待验。具体范围与结果见 [免费模型语义复验](free-semantic-acceptance.md)。

最新离线复验已完成四条流程各三轮、12 次 dry-run、24 条合成调用记录及另一数据目录的恢复读取，并修复输入正则深度和 dry-run 与实际发送内容不一致的问题。范围、测试结果和截图见 [提示词修复与离线复验](offline-acceptance.md)。本页后续模型结果保留其发生阶段；真实模型语义验收状态仍为待完成。

实施分支为 `codex/generation-trace-batch-1`，审阅基线为 `80865e39c57a475eeb330abcc9fa21800813f80f`。正式模块、两端页面、模型调用记录、角色导入、资源存储和试聊交接已实现。**首批计划尚未整体验收通过**：修正版本的四条真实模型流程尚未全部完成“连续两轮、刷新读取、服务重启后继续一轮”。

用户已批准 `ajv@8.18.0`、`esbuild@0.28.1` 和 `yaml@2.9.1`，并批准本次验收期间在后台启动三个本机服务。正式使用者身份方案按用户决定留待另议。验收服务已停止，43980、43981、43982 三个端口均已关闭。
