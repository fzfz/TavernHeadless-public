# 免费模型切换记录

## 已生效的配置

用户要求更换其他免费模型后，执行 Agent 查询 OpenRouter 官方模型目录并测试候选模型。当前验收发布配置将正文模型固定为 `nvidia/nemotron-3-ultra-550b-a55b:free`，变量更新模型固定为 `nex-agi/nex-n2.5-mini:free`。新会话的实际请求已使用该组合。

本次模型切换无需用户继续选择模型或批准付费额度。候选均使用 `:free` 标识，查询时目录中的输入与输出价格均为零；原始查询依据及逐个候选结果见 [free-model-switch.json](free-model-switch.json)，来源为 [OpenRouter 模型 API](https://openrouter.ai/api/v1/models)。

本机复验配置位于工作树 `.tmp/batch-1-free-final/config.json`；顾声慢独立流程使用同目录下的 `gush/config.json`。这些配置指向本次新建的验收数据库和单独保存的凭据文件，原有原型的本机凭据配置保持原值。凭据文件不随 Git 提交。
