# 管理 Web 端原型恢复复查

## 必须要实现的目标

设计执行者以已有 `apps/web/src` 管理 Web 端为基线，恢复差异清单中已有实际操作的功能，保留角色应用发布、Agent 配置与逐轮调试。独立的用户 Web 端继续用于用户演绎。

本轮修改 `apps/web/prototypes/admin-workspace.prototype.html`，没有修改管理 Web 端业务源码。原型仍使用内存状态；接口路径及正式联调验收沿用 [admin-round-debugging.md](admin-round-debugging.md)、[admin-editor-page-audit.md](admin-editor-page-audit.md) 和 [role-app-dual-web-plan.md](role-app-dual-web-plan.md)。

## 非本次目标

按用户指定范围，Impact 静态图表、固定进度指标，以及用户/设置/通知等未接动作按钮暂不恢复。本轮不安装依赖、不启动服务、不连接 MCP 进程，也不修改用户 Web 端。

产品页面提供当前会话和轮次的记录入口。普通试聊展示本地发生的消息状态及记录；真实后端的模型执行、提示词组装、工具与记忆结果，仍须在正式接入时逐项联调。

## 已获得的授权

用户明确要求恢复原型中遗漏的管理 Web 端功能并在恢复后复查，同时明确静态图表和未接动作按钮暂不恢复。其余已有功能继续作为增量完善的基线；未来删除或缩小已有功能前，执行者必须提交理由与影响并取得用户允许。
