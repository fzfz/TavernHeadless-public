## 1. 打开原型

用浏览器打开 [native-card-editor.prototype.html](../../../apps/web/prototypes/native-card-editor.prototype.html)。页面包含全部样式、脚本和示例数据，可以直接打开。页面使用内存数据模拟后端接口，刷新后恢复初始数据。

页面只呈现面向使用者的操作、状态和错误提示。原型的实现范围和检查限制记录在本文档中。

原型依据 [编辑器方案](native-card-editor.md)制作。左侧切换内容面板或包内文件，中间编辑表单或文件，编辑器中的变量更新 Agent 面板用于编辑提示词、规则，以及变量派生与校验模块。顶部提供保存、检查、预览、发布和导出操作；编辑区底部固定提供“保存”按钮。

## 2. 操作检查

| 操作 | 页面应呈现的结果 |
| --- | --- |
| 点击顶部“新建角色卡”，填写名称 | 创建独立空白角色卡；之前的角色保留在角色卡目录中，可切换打开 |
| 在包内文件的目录旁点击“＋”，或在当前内容面板点击“新增” | 默认选择当前目录，列出该目录支持的内容类型；填写名称后创建并打开 |
| 新建世界书、条目或开场 | 同时创建文件并登记世界书或开场索引；内容导航和包内文件可访问同一内容 |
| 新建后端模块、前端页面、正则或数据文件 | 按目录对应的模板初始化内容；文件出现在所属内容导航和包内文件中 |
| 修改人物名称，再切换“文件” | `character.json` 显示刚修改的名称；修改 JSON 后切回表单，名称同步更新 |
| 打开世界书，新增、复制、上移或删除条目 | 条目列表和对应包内文件随操作更新 |
| 新增开场并修改初始变量 | 新开场拥有单独的正文和初始变量文件 |
| 编辑变量字段，选择由模型更新或脚本派生 | 变量结构和变量更新配置分别记录字段与更新职责 |
| 打开变量更新 Agent 面板 | 显示提示词、规则和模块编辑；运行模型由系统设置管理 |
| 新增文件、上传图片，或重命名开场正文文件 | 文件树更新；重命名后 JSON 中对应的文件引用同步更新 |
| 在文件视图输入错误 JSON，或填写不存在的资源路径后检查 | 页面显示文件位置及修正入口 |
| 打开预览并切换页面、提示词、变量更新、试聊 | 各面板显示当前角色卡的对应演示结果 |
| 点击预览行动选项，或在试聊输入后按 Enter | 用户消息立即显示，示例回复分段出现；Shift + Enter 换行 |
| 保存、检查并发布 | 页面生成内存中的发布版本，可继续建立角色卡或选择版本导出 |
| 点击顶部“打包下载 ZIP” | 选择已保存修订或发布版本；首次保存前提供“保存并打包”，已有保存记录且存在修改时额外提供“打包上次保存内容” |
| 打包时关闭窗口并继续编辑 | 底部显示打包任务入口；任务固定使用开始时的修订，后续修改保留在编辑器中 |
| 打包完成或失败 | 完成后提供“下载 ZIP”和“重新打包”；服务失败时提供“重试打包” |

## 3. 演示范围

原型按后端保存流程呈现交互：编辑后标记未保存；用户点击“保存”后进入保存中状态；模拟接口成功后更新保存时间，失败时保留修改并显示重试入口。正式实现由后端接口保存。JSON 检查会检查语法及代码中已识别的文件引用，世界书检查会识别重复标识。

角色目录提供“打开内置角色包”，载入雾港来信。打包任务、进度和下载响应使用内存数据模拟后端；点击下载会更新交互状态，当前原型不生成或下载实际 ZIP。正式实现由后端解包、保存文件、生成 ZIP 并提供下载接口。

页面预览使用固定示意布局。提示词页按当前数据演示部分组装过程；变量更新使用固定提案；试聊使用固定文本模拟流式回复。正式 dry-run、脚本执行、模型请求、数据库保存与发布属于后续实现。

## ZIP 导入审批交互

入口位于编辑器顶部和角色卡目录的“导入原生 ZIP”。用户选择文件后点击“检查角色包”，检查通过后查看资源清单，点击“确认导入”，成功后打开已保存的角色卡。检查失败显示文件位置和修正操作；写入失败提供重试入口。正在导入时确认按钮保持禁用。

本轮原型模拟上传、检查和保存响应：所选文件名进入页面，检查结果和导入内容使用内置“雾港来信”资源。原型尚未解析所选 ZIP、调用后端或持久保存文件。正式接入按[联调计划](native-card-production-integration.md)执行。

用户已于 2026-09-28 批准入口位置、选择与检查分步、资源清单、导入确认、失败重试及成功打开编辑器的交互，原型审批完成，实施进入正式前后端接入阶段。自动检查覆盖成功、检查拒绝、写入失败、重复确认和导入前置条件。主 Agent 按上述验收记录位置保存正式页面的视觉、文件选择器与真实下载结果。
