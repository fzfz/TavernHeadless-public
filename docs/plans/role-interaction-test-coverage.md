## 验收边界

确定性供应商用于验证传输与恢复。外部模型的语义质量与可用性另行验收。本次交互验收无需调用收费模型。

用户随后提供了 `梦鲸思客V4-0902.json`。该文件为 1,329,446 字节，包含 114 个 prompts 和 110 个顺序项。正式 SDK 序列化后的请求体为 1,273,641 字节；修复前真实接口返回 HTTP 413、`payload_too_large`，确认超过原默认 1 MiB 上限。修复后预设、世界书、正则三类资源各自的导入接口和更新接口，共六个接口统一读取 `packages/shared/src/config/prompt-asset-request-limits.json` 的 `bodyLimitBytes`，当前值为 8,000,000 字节。原文件经正式 SDK 导入和导出后，提示词及顺序数组保持一致；经前端预览、创建、读取编辑器、保存和导出后，114 个条目、110 个顺序项及源文件已有字段保持一致。编辑器会把缺省正文和插入位置分别规范化为 `""` 和 `0`，因此编辑后的 JSON 不保证与原文件逐字相同。文件正文仅用于本机隔离验收，不加入仓库。

`docs/plans/admin-editor-page-audit.md` 提出的槽位工具能力和回合流程分别依据页面入口、角色发布 schema 和会话快照验收，当前仍需逐项核对。最终交付结论依据本记录的自动化检查和浏览器验收结果。
