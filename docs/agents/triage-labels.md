# Triage labels

Agent 必须按下表将 Skill 中的分类角色映射为 GitHub Issue 标签。

| 分类角色          | 标签              | 含义                             |
| ----------------- | ----------------- | -------------------------------- |
| `needs-triage`    | `needs-triage`    | 维护者需要评估该 Issue。         |
| `needs-info`      | `needs-info`      | 报告者需要补充信息。             |
| `ready-for-agent` | `ready-for-agent` | 规格已明确，Agent 可以独立实现。 |
| `ready-for-human` | `ready-for-human` | 该 Issue 需要人工实现。          |
| `wontfix`         | `wontfix`         | 维护者已决定放弃处理该 Issue。   |
