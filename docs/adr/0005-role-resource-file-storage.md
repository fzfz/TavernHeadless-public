# 角色包文件按版本保存在后端持久目录

后端将角色包的脚本、模板、媒体和预置文件保存在后端持久数据目录，数据库保存账号归属、角色版本、包内路径和文件元数据。资源 API 与后端模块加载器依据同一版本索引读取文件，已有会话继续引用原版本。业务记录、显示快照和模型调用历史继续由数据库保存。

原型将角色包文件保存在数据库 BLOB，再将后端脚本写出到模块目录执行。正式方案采用固定版本文件集，使媒体交付和后端脚本执行共用持久文件来源。代价是文件系统与数据库需要分步提交；备份需要保存数据库与角色文件，恢复需要用同一份备份还原两者。

目录、路径配置、提交失败处理、资源生命周期与恢复验收统一由[首批计划的文件存储章节](../plans/generation-trace-batch-1.md#后端运行数据与文件存储)定义。
